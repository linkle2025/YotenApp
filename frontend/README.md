# 四柱推命アプリ - フロントエンド

## セットアップ

1. 依存パッケージのインストール
```bash
npm install
```

2. 環境変数の設定（オプション）
`.env`ファイルを作成し、以下の内容を設定：
```
REACT_APP_API_URL=http://localhost:8000/api
```

3. 開発サーバーの起動
```bash
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## ビルド

本番環境用のビルド：
```bash
npm run build
```
