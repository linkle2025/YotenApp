# 4. 骨格（Skeleton）

[03_構造.md](./03_構造.md) で決めた画面ごとに、**何をどこに置くか**を決めます。

- 色や書体などの見た目は決めません（[05_表層.md](./05_表層.md) で決めます）。
- 図は配置を示すための略図です。細部はデザインの段階で詰めます。
- **スマートフォンを基準**に描き、パソコンでの違いを添えます。

---

## 4.1 画面幅とレイアウトの基本

| 区分 | 画面幅 | レイアウト |
|---|---|---|
| スマートフォン | 〜767px | 1列。左右の余白16px。下部にタブ（会員区域） |
| タブレット | 768〜1023px | 1列または2列。タブは上部のヘッダーへ |
| パソコン | 1024px〜 | 最大幅を決めて中央寄せ。鑑定表は2列 |

- 本文の最大幅：読み物は 720px、フォームは 560px、一覧・管理画面は 1200px、鑑定表は 1440px。
- 現行は 767px と 768px の区切りが混在していたため、上の区切りに統一します。

---

## 4.2 共通の部品

全画面で同じ部品を使います（現行は画面ごとに作られ、見た目と動きがばらばらでした）。

| 部品 | 用途 |
|---|---|
| ヘッダー | ロゴ、メニュー。スマートフォンではロゴと右上のメニューボタンだけ |
| 下部タブ | 会員区域のスマートフォン用。ホーム・つくる・記録・マイページ |
| ボタン | 主・副・控えめ・危険の4種類。送信中は二重送信できない状態にし、くるくる回る印を出す |
| 入力欄 | ラベルは常に欄の上に表示。補足は下、誤りの文言も下 |
| 生年月日の入力 | 年・月・日をまとめた専用部品。存在しない日付を選べない（4.4 参照） |
| 出生地の選択 | 都道府県の一覧。地方ごとに区切り、文字入力で絞り込める |
| カード | 鑑定記録、能力、職種などのまとまり |
| パネル | 画面内で詳細を開く。スマートフォンは下から、パソコンは右から出る |
| 確認パネル | 削除など取り返しのつかない操作の確認。消えるものを具体的に書く |
| トースト | 成功などの短い知らせ。数秒で消える。「元に戻す」を付けられる |
| スケルトン | 読み込み中に、内容の形だけを薄く表示する |
| 空の状態 | 絵・説明・次の操作のボタン |
| エラーの表示 | 何が起きたか・どうすればよいか・再試行ボタン |
| ランクの印 | 鑑定スキル表の S〜D |
| 五行の印 | 木・火・土・金・水を色と文字の両方で示す（色だけに頼らない） |

## 4.4 命式作成 `/readings/new`

```
┌───────────────────────────┐
│ ← 戻る     命式をつくる        │
├───────────────────────────┤
│ 氏名（任意）                  │
│ [ 山田 太郎              ]   │
│                           │
│ 生年月日                     │
│ [ 1985 ▼][ 5 ▼][ 10 ▼]     │  ← 1つの部品。和暦も併記（昭和60年）
│                           │
│ 生まれた時刻                  │
│ [ 11 ▼]時 [ 30 ▼]分          │
│ □ 時刻がわからない            │  ← チェックすると時刻欄を隠し、
│                           │     「時柱を使わずに出します」と表示
│ 生まれた場所                  │
│ [ 岐阜県                ▼]   │  ← 地方ごとの一覧＋絞り込み
│ ⓘ 県庁所在地の経度で時刻を補正します│
│                           │
│ 性別                        │
│ ( 男性 ) ( 女性 )             │  ← 2択はボタン型
│ ⓘ 大運の向きの判定に使います     │
│                           │
├───────────────────────────┤
│ [      命式をつくる      ]    │  ← 画面下に固定
└───────────────────────────┘
```

- 生年月日：年は 1901〜2040。月を変えたら、その月にない日は選べなくする。スマートフォンでは数字キーで直接入力もできる。
- 入力の誤りは、項目のすぐ下に表示する。
- 送信中はボタンを「計算しています」にして、二重送信を防ぐ。
- パソコンでは、フォームを中央 560px に置く。

## 4.5 鑑定表 `/readings/[id]`

アプリの中心の画面です。情報が多いので、**上から「概要 → 根拠 → 詳細」の順**に並べます。

### スマートフォン

```
┌───────────────────────────┐
│ ← 記録     山田太郎さん  [⋯]  │  ← [⋯]：お気に入り・印刷・削除
├───────────────────────────┤
│ [日干の画像]                  │
│ 己（つちのと）・田畑            │
│ 1985年5月10日 11:30 岐阜県 男性│
│ ⓘ 時刻不明のため参考値（該当時）│
│                           │
│ ┌─ ひとことで ───────────┐ │
│ │ （判定の要点の要約。未生成   │ │
│ │  なら生成ボタン）           │ │
│ └───────────────────────┘ │
│                           │
│ [スキル表][命式][五行][運勢]   │  ← 区切りのタブ（固定表示）
│                           │
│ ■ スキル表                   │
│  向いている職種                │
│  教官 S ─────────── 86  │
│   └ AIの説明（1〜3文）        │
│  軍師 A+ ───────── 82     │
│  …（7職種、点数の高い順）       │
│                           │
│  9つの能力                    │
│  ┌企画 90┐┌知略 82┐┌実行 80┐ │  ← 2列のカード
│  …                          │
│  （カードを押すと内訳とAIの説明） │
│                           │
│  活かし方：…                  │
│                           │
│ ■ 命式                      │
│  ┌──┬──┬──┬──┐           │
│  │時│日│月│年│              │
│  ├──┼──┼──┼──┤           │
│  │庚│己│辛│乙│ 天干           │
│  │傷官│ │食神│偏官│ 通変星    │  ← 押すと解説パネル
│  │午│酉│巳│丑│ 地支           │
│  │丁│辛│丙│己│ 蔵干（本気）     │
│  └──┴──┴──┴──┘           │
│  [中気・余気も表示]             │
│  干合：…                      │
│                           │
│ ■ 五行バランス                 │
│  （日干の五行を上にした五角形）    │
│  身旺（比劫＋印 ＞ 食傷＋財＋官。数値も表示）│
│  格局：傷官格                   │
│                           │
│ ■ 運勢（段階2・要確認）         │
│  大運・年運                    │
└───────────────────────────┘
```

- 画面の順序は「スキル表 → 命式 → 五行」を基本にします。会員の多く（経営者・保護者）にとって、まず知りたいのは「強み」だからです。占者には「命式」を先に見せる設定を、段階4で検討します（要確認）。
- タブは、押すとその区切りまで移動するだけで、内容は1ページに全部並んでいます（印刷・検索・読み上げのため）。

### パソコン（1024px〜）

```
┌──────────────────────────────────────────────┐
│ [ロゴ]  ホーム つくる 記録 マイページ            [○○さん▼] │
├──────────────────────────────────────────────┤
│ ← 記録   山田太郎さん  己（田畑） 1985/5/10 11:30 岐阜 男性 [☆][印刷][⋯]│
├──────────────────┬───────────────────────────┤
│ 命式（表）          │ ひとことで（判定の要点の要約）        │
│                  │                               │
│ 五行バランス（図）    │ 向いている職種（7件、AIの説明付き）    │
│ 身旺・格局・干合     │                               │
│                  │ 9つの能力（3×3のカード）            │
│ ※左は上下に動かしても │                               │
│  見える位置に固定    │ 活かし方                         │
│                  │ 運勢（段階2）                      │
└──────────────────┴───────────────────────────┘
```

左の列（根拠）を見ながら、右の列（結果と説明）を読める配置にします。現行の横長レイアウトの考え方を引き継ぎます。

### 判定の要点の状態

| 状態 | 表示 |
|---|---|
| 未生成 | 説明「点数とランクの根拠を、AIが日干を起点に説明します」＋［判定の要点をつくる］＋残り回数（今日あと18回） |
| 生成中（段階1） | 進み具合の表示（「命式を読み取っています」→「職種の説明を書いています」など）。約30秒の目安を示す |
| 生成中（段階2） | 要約から順に、書き上がった文章をその場に表示していく。各職種・能力の説明も、できた順に埋まる |
| 完了 | 文章。最下部にモデル名、生成日時、「AIによる解説で、断定ではありません」 |
| 入力が変わった | 「解釈ルールが更新されました。新しい点数で説明をつくり直せます」＋［つくり直す］ |
| 上限に達した | 「今日の生成回数の上限に達しました。明日またお試しください」 |
| 失敗 | 理由に応じた文言＋［もう一度試す］ |
| 機能停止中 | 「現在、判定の要点はつくれません」（ボタンは出さない） |

```
┌───────────────────────────┐
│          記録          [＋] │
├───────────────────────────┤
│ [🔍 氏名で検索             ] │

│                           │
│ ┌───────────────────────┐ │
│ │[甲] 山田太郎        ☆ ⋯ │ │  ← 左に日干の印
│ │    1985/5/10 11:30 岐阜   │ │
│ │    作成 11/08              │ │
│ └───────────────────────┘ │
│ ┌───────────────────────┐ │
│ │[丙] 佐藤花子        ★ ⋯ │ │
│ │    1990/3/10 時刻不明 大阪 │ │  ← 時刻不明は時刻を出さない
```

- 空のとき：「まだ記録がありません」＋［命式をつくる］。

## 4.7 十干・通変星の解説

### 一覧 `/jikkan`

十干10件のカードを、五行ごとにまとめて並べます（木：甲・乙、火：丙・丁 …）。各カードに画像、名前、読み、比喩（樹木など）、一言の特徴。

### 個別 `/jikkan/[slug]`

```
┌───────────────────────────┐
│ ← 十干の一覧                 │
│ [画像]                       │
│ 甲（きのえ）                   │
│ 木の陽 ・ 樹木                 │
│                           │
│ ■ 特徴                       │
│ ■ 人物像                      │
│ ■ 強み・活かし方               │
│ ■ 弱み・接し方の注意点          │
│                           │
│ ─ 他の十干 ─────────────── │
│ [乙][丙][丁]…                 │
│                           │
│ [ 自分の日干を調べる（無料診断）]  │  ← 段階3
└───────────────────────────┘
```

鑑定表から開いたときは、同じ内容をパネルで表示します（ページは移らない）。パネルには「ページで開く」のリンクも付けます。

通変星（`/tsuhensei`、`/tsuhensei/[slug]`）も同じ構成です。項目は、キャラクター・才能・弱点。

## 4.8 認証の画面

### 会員登録 `/signup`

```
┌───────────────────────────┐
│ 会員登録                     │
│ 表示名      [            ]   │
│ メールアドレス [            ]   │
│ パスワード   [         ] [👁]  │
│  8文字以上（強さの目安を表示）     │
│ □ 利用規約とプライバシーポリシーに同意 │
│ [     登録する      ]         │
│ すでに会員の方 → ログイン        │
└───────────────────────────┘
```

登録後：「確認メールを送りました」の画面。メールのリンクを押すと、プロフィール入力へ進みます。

### プロフィール入力（登録直後）

命式作成と同じ入力部品で、生年月日・時刻・出生地・性別を入力します。「あとで入力する」で飛ばせます。入力すると、本人の鑑定表へ移ります。

### ログイン `/login`

メールアドレス、パスワード（表示切り替え付き）、［ログイン］、「パスワードを忘れた場合」、「会員登録はこちら」。ログイン後は、元いた画面かホームへ移ります。

### パスワード再設定 `/forgot-password`・`/reset-password`

現行の流れを引き継ぎます。申し込み後は「メールを送りました」の表示に切り替えます。リンクが無効なら、理由と、もう一度申し込むボタンを出します。

## 4.10 管理区域

パソコンでの利用を基本にします。スマートフォンでも閲覧できるようにします。

### ユーザー管理 `/admin/users`

```
┌──────────────────────────────────────────────┐
│ 管理  [ユーザー][生成状況][奇門遁甲][解釈ルール]         │
├──────────────────────────────────────────────┤
│ [🔍 名前・メールで検索]  ロール:すべて▼ 状態:すべて▼       │
│ 表示名 │ メール │ ロール │ 状態 │ 登録日 │ 最終ログイン │ 記録 │ ⋯ │
│ ……                                              │
└──────────────────────────────────────────────┘
```

- 行の ⋯ から、ロール変更・停止・再開・削除。編集は行の中ではなく、右から出るパネルで行う（誤操作を防ぐ）。
- スマートフォンでは表をカードの一覧に切り替える。

### 生成状況 `/admin/usage`

期間ごとの判定の要点の生成数、トークン数、利用の多い会員、エラーの件数。

### 奇門遁甲 `/admin/kimon`

```
┌──────────────────────────────────────────────┐
│ (時盤)(日盤)                                     │
│ 日付[2026-11-09] 時刻[10:00] 場所[東京都▼]          │
│ 詳細設定 ▸（陰陽・局数の手動指定）                     │
│ [作盤する]  [1日分を見る]                           │
├──────────────────────────────────────────────┤
│ 干支：丙午年 己亥月 … 陽○局                          │
│ ┌────┬────┬────┐                              │
│ │ 巽4 │ 離9 │ 坤2 │  ← 各宮：天盤干・地盤干・九星・八門・八神・格局・点数│
│ ├────┼────┼────┤                              │
│ │ 震3 │ 中5 │ 兌7 │                              │
│ ├────┼────┼────┤                              │
│ │ 艮8 │ 坎1 │ 乾6 │                              │
│ └────┴────┴────┘                              │
│ 用途：[年運][疾病][男女][失せ物]  凡例 ▸             │
└──────────────────────────────────────────────┘
```

- 現行の作盤手順のデバッグ表示は、管理者向けの「計算の過程」として折りたたんで残します（要確認）。
- 1日分 `/admin/kimon/daily`：12の盤を並べる。失敗した時刻だけ、その枠にエラーと［再試行］を出す。

### 解釈ルール `/admin/rules`

段階1：現在のルールの内容（原則、喜忌、日干、判定ルール）と版を読みやすく表示する（編集はファイルで行う）。
段階4：編集、試算（鑑定記録を選んで、変更前後の点数を並べる）、公開。

## 4.11 無料診断（段階3）

### 入力 `/shindan`

生年月日（必須）、時刻（任意）、性別（任意。大運を出さないなら不要）。出生地は既定で東京都とし、変えられるようにする（要確認）。

### 結果 `/shindan/result`

