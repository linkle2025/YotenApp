# 付録A 鑑定ロジック仕様

現行の Python 版（`backend/apps/fortune/`）の計算ルールをまとめたものです。TypeScript へ移植するときの基準にします。

- **現行の挙動を正確に写すこと**を目的にしています。不具合とわかっている箇所は「⚠ 不具合」と書き、新版での扱いを添えています。
- 数値の大きな表は、ファイル名と行の範囲で参照しています（2026-11-09 時点の行番号）。
- 正しさの最終的な基準は、お手本サイトとの照合で作る正解データです（[02_要件.md の F-21](./02_要件.md#f-21-正解データによる照合段階0)）。現行のルールと正解データが食い違ったら、正解データを優先して、この付録を直します。

| 性別 | male / female |

## A.2 時刻の補正

**補正後の時刻（分）＝ 時×60 ＋ 分 ＋ 都市の補正 ＋ 月ごとの均時差**

- 0分未満なら前日、1440分以上なら翌日に送ります。
- 都市の補正：`calculators.py` 41-92行（札幌 +25、東京 +19、岐阜 +7、大阪 +2、那覇 −29 など）。表にない都市は東京（+19）として扱われます。
- 均時差（月ごとの固定値）：`calculators.py` 96-109行。1月 −3、2月 −13、3月 −12、4月 −4、5月 +3、6月 +2、7月 −3、8月 −6、9月 0、10月 +10、11月 +16、12月 +11。

> ⚠ **不具合：時間不明のときも0時として補正している**。補正が負になる地域・月（大阪の3月など）では、日柱が前日にずれます。
> 実測：1990-03-10・大阪・時間不明 → 日柱 癸酉（正しくは甲戌）。
> **新版：時間不明のときは補正せず、入力した日付をそのまま使う。**

> 精度の注意：均時差は月の中でも数分変わります。補正後の「地方の太陽の時刻」と、日本標準時で書かれた節入り時刻をそのまま比べているので、節入りの前後数十分で月柱・年柱が揺れる可能性があります。正解データで確かめてください。

## A.3 四柱

### 年柱

1. 補正後の日時が、その年の立春（`solar_terms.json` の時分まで）より前なら、前年として扱う。
2. `n = (年 − 1984) mod 60`。天干 = 十干[n mod 10]、地支 = 十二支[n mod 12]（1984年 = 甲子）。

`calculators.py` 427-497行。

### 月柱

その年の12の節を日時順に並べ、補正後の日時までに最後に通過した節の `month_pillar` をそのまま使います（計算式では出しません）。`calculators.py` 500-593行。

> ⚠ **不具合：1月1日から小寒までの月柱が誤る**。前年の節を探すときに、前年1月の小寒（丑月）を拾ってしまいます。
> 実測：1990-01-03 → 月柱 乙丑（正しくは丙子）。1901年1月1日〜5日は前年のデータがなく、エラーになります。
> **新版：前年12月の大雪（子月）を正しく参照する。1901年初は対応範囲外として入力で止める。**

### 日柱

対象日以前で最も近い節（当年と前年）の `day_pillar` を基準にして、日数の差だけ60干支を進めます。時刻は見ず、日付だけで決めます。`calculators.py` 596-679行。

- **23時台でも日を替えません**（23時台を翌日として扱う流派もあります）。ただし時刻を補正した結果が0時を過ぎれば翌日になるため、東京の6月なら23時39分以降（補正 +21分）が翌日の日柱になります。
- **新版：お手本サイトの扱いに合わせる**（2026-11-09 決定）。[付録D](./付録D_正解データ用テストケース.md) の No.19〜23 で確定させる。
- ⚠ 基準の節が見つからないときの予備処理が「1900-01-01 を甲子」としていますが、実際は甲戌です。新版では予備処理を設けず、範囲外は入力で止めます。

### 時柱

- 地支 = 十二支[((時 + 1) ÷ 2 の切り捨て) mod 12]（23時は子）
- 天干 = 十干[(日干の番号 × 2 ＋ 地支の番号) mod 10]（五鼠遁）

`calculators.py` 682-699行。

### 蔵干

中国式の表です。`calculators.py` 113-126行。子・卯・酉は本気だけ、午は中気が己で本気が丁、亥は中気が甲で本気が壬、など。

### 通変星

日干と対象の干の10×10の表です。`calculators.py` 146-157行。

### 基準ケース（現行の計算結果）

| 入力 | 年柱 | 月柱 | 日柱 | 時柱 | 格局 | 大運 |
|---|---|---|---|---|---|---|
| 1985-05-10 11:30 岐阜 男性 | 乙丑 | 辛巳 | 己酉 | 庚午 | 傷官格 | 逆運、立運2歳 |

## A.4 五行バランスの点数

`calculators.py` 894-1044行。次の順に、固定の順序で適用します。同じ五行が複数の補正に当たれば、重ねてかけます。

1. **天干**：各10点。時間不明なら時柱を除く。
2. **蔵干**：本気10点（子・卯・酉の本気と、午の丁は20点）、中気5点（午の己は0点）、余気5点。亥が1つあるごとに土へ5点を足す。
3. **月令**：月支の五行（丑・辰・未・戌は土）の点数を2倍にする。
4. **死令**：月令の五行が剋す五行の点数を半分にする。相剋の順は 木→土→水→火→金→木。
5. **天干にない五行**：天干（時間不明なら3本）に現れない五行の点数を半分にする。

結果は小数（0.5刻みなど）のまま保存します。表示は、整数ならそのまま、小数なら小数点以下1桁にします。

### 表示の並び

日干の五行を上に置き、相生の順（木→火→土→金→水）に時計回りに並べます。位置の意味は、上＝比劫、右＝食傷、右下＝財、左下＝官、左＝印です。

## A.5 身旺・身弱

**身旺度 D ＝（比劫 ＋ 印）−（食傷 ＋ 財 ＋ 官）**（五行バランスの点数を、日干から見た5つのグループに分けたもの）

- D > 0：身旺、D < 0：身弱、D = 0：中和
- 現行は画面側で「-」、スキル表側で「中和」と表記が分かれています。**新版は「中和」に統一し、計算もサーバー側だけで行います。**

## A.6 格局

`calculators.py` 766-891行。

- **透干**：月支の蔵干と同じ五行の天干が、年干・月干・日干・時干のどれかにあること（陰陽は問わない。日干も含む。時間不明なら時干を除く）。
- **判定の順**
  1. 本気が透干していれば、本気の通変星の格。
  2. 余気と中気の両方が透干していれば、「余気の格 または 中気の格」（余気が先）。
  3. どちらか片方だけが透干していれば、その格。
  4. どれも透干していなければ、本気の通変星の格。
- **比肩・劫財は格にしない**。1で比肩・劫財になったら2以降へ進み、最後まで比肩・劫財なら格なし（表示は「—」）。
- 外格・破格は未実装。

## A.7 干合

現行は画面側（`DetailPage.js` 300-360行）で判定しています。**新版はサーバー側で判定し、結果に含めます。**

- 組み合わせ：甲己、乙庚、丙辛、丁壬、戊癸
- 隣り合う柱だけを見る（時と日、日と月、月と年）。時間不明なら時と日は見ない。
- 化気の成否は判定せず、点数にも反映しない。

## A.8 大運・年運

`calculators.py` 1169-1317行。現行は開発時だけ表示しています（[02_要件.md の F-09](./02_要件.md#f-09-大運年運段階2要確認)）。

- **順逆**：男性で年干が陽、または女性で年干が陰なら順運。それ以外は逆運。
- **立運**：順運は、補正後の生年月日の0時から次の節入りまでの日数。逆運は、前の節入りまでの日数＋1（両端を数える）。日数を3で割り、余りが0か1なら切り捨て、2なら切り上げ。
- **期間**：月柱から順または逆に12本。1本目は0歳から立運の前年まで、2本目以降は立運から10年ずつ。
  - ⚠ 立運が0歳のとき、1本目が「0〜−1歳」になる。新版では1本目を出さない。
- **年運**：生年から80年分の干支（1984年 = 甲子の式）と、日干から見た天干の通変星。

## A.10 解釈ルール

`skill_rules.py` と `rules/skill_rules.toml`。説明書は `doc/解釈ルール設定.md`。

- **条件（when）**：すべてを満たすと適用。条件の種類は strength、day_stem、day_element、top_group（同点も1位）、group_at_least（以上）、group_below（未満）、group_rank_within、strength_diff_at_least、strength_diff_below、kakukyoku_any、stem_stars。
- **補正（adjust）**：`value × (per に挙げた値の合計)`。per がなければ value をそのまま足す。そのあと min・max で範囲を制限する。
- **適用の順**：日干の adjust → [[rules]] を上から順に。
- **版**：`version` と内容のハッシュ（sha256 の先頭12桁）を組み合わせた値。判定の要点の入力に含め、ルールが変わったら古い解説を出さない。
- **書き間違い**：エラーにして、スキル表を出さない（誤った点数を出さないため）。新版ではデプロイ前の検査でも止める。
- 初期ルールの一覧は `doc/解釈ルール設定.md` の「初期ルール」の表を参照。

## A.12 奇門遁甲

`calculators.py` 1476-2543行、`views.py` 103-312行。点数の説明は `doc/奇門遁甲時盤点数計算.md`。

- **時盤**：時刻を補正してから四柱を出し、時柱の干支で作盤する。

- **宮の点数**：八門（休・生・開 40、景 20）、八神（符・陰・合・地・天 20）、九星（任・冲・輔・心 10）、天盤干・地盤干（乙・丙・丁 10）の単純な合計。中宮は点数なし。
- **凶格**：`kyokaku.csv` の44件（天盤×地盤の組み合わせ、門迫、三奇入墓、六儀撃刑）と、五不遇時（時干が日干を剋し、陰陽が同じ）。
- **回帰テスト**：現行は2ケースだけ（`tests/test_kimon_tonkou_board.py`）。新版の移植前に、ケースを増やす。

## A.15 移植の進め方

1. 正解データを作る（F-21）。
2. 現行の Python 版を正解データで検証し、不一致を一覧にする。
3. この付録の不具合（⚠）と、不一致の扱いを決める。
4. TypeScript 版を作る。現行の Python 版と同じ入力で同じ結果になること（不具合の修正分を除く）を、大量の入力（例：1901〜2040年の毎日×数種類の時刻・地域）で自動比較する。
