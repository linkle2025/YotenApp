# 5. 表層（Surface）

[04_骨格.md](./04_骨格.md) の配置に、**色・文字・余白・言葉づかい**を与えます。

> 色や書体は、方向性を示す**提案**です。オーナーの好みと塾のブランドに合わせて確定させてください（[付録C](./付録C_確認事項.md)）。コントラスト比は、下の値で計算して確かめています。

---

## 5.1 現行の見た目の課題

- Bootstrap 風の青（#007bff）が主色で、陽てん塾らしさがない。白文字との比は 3.98:1 で、基準（4.5:1）に届かない。
- 色・文字の大きさ・影が、画面ごとにばらばら。文字の大きさは約25段階、影は9種類が混在している。
- 同じ名前のボタンの定義（`.submit-button` など）が複数のファイルにあり、互いに上書きし合っている。
- 五行の色のうち、金（#d3d3d3）は白背景との比が 1.50:1、火（#fd899a）は 2.28:1 で、文字の色としては読めない。
- 日本語の書体を指定しておらず、端末によって見え方が大きく変わる。
- ロゴ画像・ファビコン・ホーム画面用のアイコンがない。

新版では、**デザインの共通ルール（デザイントークン）を最初に決め、すべての画面がそれを使う**ようにします。

---

## 5.2 デザインの方向性

| キーワード | 意味 |
|---|---|
| 温かい | 「陽」の字のとおり、日だまりのような温かさ。生成り色の背景と朱色 |
| 落ち着き | 東洋の占術らしい、墨・和紙の静けさ。派手な装飾はしない |
| 明快 | 点数・ランク・説明が一目でわかる。情報の強弱をはっきりつける |
| 信頼 | 占いにありがちな神秘的な演出（星空、水晶など）を避け、「根拠を示す道具」として見せる |

## 5.3 色

色は名前（トークン）で定義し、画面では名前だけを使います。

### 基本の色（ライトモード）

| トークン | 色 | 用途 | 背景との比 |
|---|---|---|---|
| `bg` | #FBF8F3 | 画面の背景（生成り） | — |
| `surface` | #FFFFFF | カード・パネルの背景 | — |
| `text` | #1F1B16 | 本文（墨） | 16.16:1 |
| `text-muted` | #5C554C | 補足・説明 | 6.93:1 |
| `primary` | #B4441F | 主ボタン・リンク・強調（朱） | 5.23:1 |
| `primary-hover` | #93361A | 主ボタンのホバー | — |
| `on-primary` | #FFFFFF | 主ボタンの文字 | 5.54:1（primary 上） |
| `accent` | #1E3A5F | 見出しの飾り・補助の強調（藍） | 10.86:1 |
| `border` | #E5DED3 | 罫線・枠 | — |
| `danger` | #B42318 | 削除・エラー | 6.57:1（白上） |
| `success` | #18794E | 成功の知らせ | 5.41:1（白上） |

### 五行の色

五行は**色と文字の両方**で示します（色の見分けが難しい人のため）。セルや印の背景には淡い色、文字には濃い色を使います。

| 五行 | 文字 | 背景（淡） | 比 | 現行 |
|---|---|---|---|---|
| 木 | #2F6B2F | #E6F2E3 | 5.57:1 | #317431 |
| 火 | #B3261E | #FCE8E6 | 5.55:1 | #fd899a（文字には不可） |
| 土 | #8A4B14 | #F5EADB | 5.71:1 | #a25a1c |
| 金 | #5E6470 | #EEF0F3 | 5.21:1 | #d3d3d3（文字には不可） |
| 水 | #0B6A8F | #E1F2F9 | 5.26:1 | #0fa6d9 |

現行の五行の色に近い色相を保ちつつ、読める濃さに調整しています。

### ランクの色（鑑定スキル表）

10段階（S〜D）を5つの色の段階にまとめます。ランクの文字（S、A+ など）は必ず併記します。

| ランク | 背景 | 文字 | 比 |
|---|---|---|---|
| S | #8E2A12 | #FFFFFF | 8.43:1 |
| A+・A | #B4441F | #FFFFFF | 5.54:1 |
| B+・B・B− | #F2C14E | #1F1B16 | 10.20:1 |
| C+・C・C− | #D9D4CC | #1F1B16 | 11.61:1 |
| D | #F1EEE9 | #5C554C | 6.35:1 |

### ダークモード（段階2）

端末の設定に合わせて切り替えます。主な色は次のとおりです。

| トークン | 色 | 比 |
|---|---|---|
| `bg` | #17140F | — |
| `text` | #EDE7DE | 14.94:1 |
| `text-muted` | #B5ADA2 | 8.28:1 |
| `primary` | #F08A5D | 7.43:1 |

五行・ランクの色は、ダークモード用に別途調整します。

## 5.4 文字

### 書体

| 用途 | 書体 | 理由 |
|---|---|---|
| 本文・画面の文字 | Noto Sans JP | 読みやすく、端末による差が小さい |
| 見出し・ロゴまわり・十干の名前 | Noto Serif JP（または Zen Old Mincho） | 東洋の占術らしい落ち着き。使うのは見出しだけにする |
| 数字（点数） | Noto Sans JP の等幅数字 | 点数の桁がそろって比べやすい |

Web フォントは Next.js のフォント最適化（`next/font`）で読み込み、表示の遅れを防ぎます。

### 文字の大きさ

8段階に絞ります（現行は約25段階）。

| トークン | 大きさ | 行の高さ | 用途 |
|---|---|---|---|
| `xs` | 12px | 1.5 | 注記・出典 |
| `sm` | 14px | 1.6 | 補足、表の文字 |
| `base` | 16px | 1.8 | 本文（スマートフォンでも16px未満にしない） |
| `lg` | 18px | 1.7 | 説明文の強調、カードの見出し |
| `xl` | 20px | 1.5 | 区切りの見出し |
| `2xl` | 24px | 1.4 | 画面の見出し |
| `3xl` | 30px | 1.3 | 鑑定表の日干、トップの見出し |
| `4xl` | 36px | 1.2 | 点数の大きな表示 |

日本語の本文は、行の高さを広め（1.8）にとります。

## 5.5 余白・角丸・影

| 項目 | 決まり |
|---|---|
| 余白 | 4px を単位に、4・8・12・16・24・32・48・64 の8段階 |
| 角丸 | 小 6px（入力欄・印）、中 12px（カード・ボタン）、大 20px（パネル）、丸（タグ） |
| 影 | 2段階だけ。カード：`0 1px 3px rgba(31,27,22,.08)`、パネル：`0 8px 24px rgba(31,27,22,.12)` |
| 罫線 | 1px の `border` 色。区切りは罫線より余白で表す |

## 5.6 部品の見た目

| 部品 | 見た目 |
|---|---|
| 主ボタン | `primary` の背景に白文字。高さ48px（スマートフォンで押しやすい大きさ）、角丸12px |
| 副ボタン | 白背景に `primary` の枠と文字 |
| 控えめなボタン | 文字だけ（`primary` 色） |
| 危険なボタン | `danger` の背景に白文字。確認パネルの中でだけ使う |
| 入力欄 | 白背景、`border` の枠、高さ48px。選択中は `primary` の枠と薄い光彩。誤りのときは `danger` の枠と下に文言 |
| カード | `surface` 背景、角丸12px、カードの影 |
| 命式の表 | 罫線は細く、天干・地支の文字は大きく（`2xl`、明朝体）。セルの背景に五行の淡い色、文字に五行の濃い色 |
| 能力のカード | 能力名、点数（等幅の大きな数字）、0〜100の横棒（`primary`） |
| 職種の行 | 職種名、ランクの印、点数の横棒。AIの説明は行の下に `text-muted` で |
| 判定の要点 | 本文は `lg`。生成中の文章の末尾に点滅するカーソルを表示する（段階2） |

アイコンは、線の細い1種類のセット（Lucide など）に統一します。

## 5.7 画像とブランド

| 項目 | 方針 |
|---|---|
| ロゴ | 「陽てん塾」の文字ロゴを作る（要確認：既存のロゴがあれば使う） |
| ファビコン・ホーム画面用のアイコン | ロゴから作る（現行はない） |
| 十干の画像 | 現行の10点を引き継ぐ。画質と雰囲気が新しい方向性に合うか確認し、必要なら作り直す |
| 未使用の画像 | 現行の `public/img` にある未使用の8点（五行・太極・十二支）は、使い道が決まるまで引き継がない |
| SNS 共有用の画像（OGP） | ページごとに自動で作る（十干のページなら、その十干の画像と名前） |
| 写真 | 原則使わない。使う場合は塾の実際の写真に限る |

## 5.8 動き

- 動きは「状態が変わったことを伝える」ためだけに使う（パネルの出入り、トースト、横棒が伸びる、など）。
- 時間は 150〜250ms。派手な演出はしない。
- 端末で「視差効果を減らす」設定がオンなら、動きを止める。

## 5.9 言葉づかい（トーン＆マナー）

### 基本

| 決まり | 例 |
|---|---|
| 「です・ます」調 | 「命式をつくりました」 |
| 断定しない | ○「人をまとめる力が出やすい傾向があります」 ×「リーダーに向いています」 |
| 運勢・吉凶を言わない | ×「運気が開けます」「凶です」 |
| 低い項目も活かし方で終える | ○「管理は仕組みやツールで補うと安定します」 |
| 専門用語には短い補足を付ける | 「印（学ぶ力・吸収する力）」「食傷（表現する力・形にする力）」 |
| 操作の言葉は動詞で短く | ［命式をつくる］［保存する］［削除する］ |
| 呼び方をそろえる | 「鑑定記録」（現行の「履歴」「計算履歴」は使わない）、「出生地」「生まれた場所」は画面では「生まれた場所」に統一 |

判定の要点（AI）の文章の決まりは、現行のプロンプト（`skill_insight_v2.md`）と解釈ルールの `principles` を引き継ぎます。

### 状態ごとの文言の例

| 場面 | 文言 |
|---|---|
| 空の記録 | 「まだ記録がありません。生年月日を入れると、命式と強みがわかります。」［命式をつくる］ |
| 通信の失敗 | 「通信がうまくいきませんでした。電波の良いところで、もう一度お試しください。」［もう一度試す］ |
| サーバーの不具合 | 「うまく処理できませんでした。時間をおいて、もう一度お試しください。」（「コンソールを確認」などは書かない） |
| 存在しない日付 | 「この月は30日までです。」 |
| 範囲外の生年 | 「1901年〜2040年の生まれに対応しています。」 |
| 時刻不明の注記 | 「生まれた時刻がわからないため、時柱を使わずに出した参考値です。」 |
| 削除の後 | 「『山田太郎』の記録を削除しました。」［元に戻す］ |
| 判定の要点の上限 | 「今日の生成回数の上限に達しました。明日またお試しください。」 |
| 退会の確認 | 「退会すると、プロフィールと鑑定記録12件、判定の要点がすべて削除され、元に戻せません。」 |

## 5.10 アクセシビリティ

| 項目 | 決まり |
|---|---|
| コントラスト | 文字と背景は 4.5:1 以上（大きな文字は 3:1 以上）。この章の色はすべて満たしている |
| 色だけに頼らない | 五行・ランク・エラーは、色と文字（または印）を併用する |
| キーボード操作 | すべての操作をキーボードでできる。選択中の場所がはっきり見える枠を出す |
| パネル・確認 | Esc で閉じる。開いている間は、操作の対象をパネルの中に閉じ込める（focus trap）。閉じたら元の場所に戻る |
| 読み上げ | 画像に代わりの文字（十干の画像なら「甲（樹木）」）。命式の表は、行と列の見出しを読み上げられる作り。点数の横棒には数値を併記 |
| 押せる大きさ | ボタンやリンクは 44×44px 以上 |
| 文字の拡大 | ブラウザで200%に拡大しても、内容が欠けない |

## 5.11 実装の方針（参考）

- デザイントークンは CSS 変数で定義し、Tailwind CSS の設定から参照する（案）。
- 部品は、アクセシビリティに配慮した既製の部品集（shadcn/ui など）をもとに、この章の見た目に合わせて作る（案）。
- 部品の一覧と見た目を確認できるカタログ（Storybook など）を用意するかは要確認。
