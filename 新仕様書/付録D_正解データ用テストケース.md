# 付録D 正解データ用テストケース

お手本サイト（会員制）で同じ条件の命式を出し、空欄の「お手本」の列に結果を書き込むための表です。今のアプリの計算結果（2026-11-09 時点）を「現行」の列に並べているので、ずれた箇所がすぐわかります。

- 作成：2026-11-09。境界のケースは、`solar_terms.json` の節入り時刻を元に「何分前・何分後」で作っています。
- ここにある生年月日は、すべて架空の条件です（実在の人物ではありません）。
- 書き込みが終わったら、新版の TypeScript 版の自動テストの期待値にします（[02_要件.md の F-21](./02_要件.md#f-21-正解データによる照合段階0)）。

## D.3 結果の読み方

お手本の結果から、次の4つの方針がわかります。わかったら [付録A](./付録A_鑑定ロジック仕様.md) に反映します。

| 知りたいこと | 見るケース | 判断の仕方 |
|---|---|---|
| **地方時の補正をしているか** | No.7、8（立春の那覇・札幌）、No.17（大雪の20分前）、No.27〜30（時柱の境目） | お手本が「見るポイント」に書いた「補正なしなら」の結果と一致すれば、補正していない |
| **23時台を当日・翌日のどちらとするか** | No.19〜23（日の境目） | No.19（23時30分）の日柱が「癸亥」なら翌日扱い、「壬戌」なら当日扱い |
| **時間不明のときの扱い** | No.24〜26 | No.24 の日柱が「甲戌」ならよい（現行は誤り）。No.25 で年柱・月柱がどちらになるか |
| **1月初めの月柱** | No.9、12 | 「丙子」になる見込み（現行は「乙丑」で誤り） |

### 23時台の扱い（決定）

**お手本サイトに合わせます**（2026-11-09 決定）。No.19〜23 の結果で、当日扱いか翌日扱いかを確定させてください。

### 見込みと違ったとき

お手本の結果が、ここに書いた「見込み」とも現行とも違う場合は、No. と項目を控えておいてください。節入り時刻のデータや、蔵干・格局の流派の違いが原因の可能性があるので、1件ずつ原因を調べます。

## D.4 追加してほしいケース

## D.5 照合の結果（2026-11-11）

お手本サイトの画面（命式48枚・奇門遁甲11枚）を書き写し、新版と突き合わせた。書き写した結果は自動テストの期待値にしている（`packages/meishiki/test/fixtures/reference-*.json`、テストは `reference-meishiki.test.ts`・`kimon-reference.test.ts`）。画面のキャプチャそのものはリポジトリに入れない（`raw/kimon_検証/`）。

### お手本サイトの決まり（新版の既定値にした）

| 項目 | お手本サイト | 現行版（旧版） |
|---|---|---|
| 時刻の補正 | 出生地の経度差だけ（均時差は使わない） | 経度差＋均時差 |
| 年柱・月柱の節入り | 補正前の日本標準時で比べる | 補正後の時刻で比べる |
| 日柱 | 補正後の日付 | 同じ |
| 23時台の時柱 | 翌日の子の刻（翌日の日干から時干を出す）。境目の設定によらない | 当日の日干から出す |
| 日の境目 | 「境界23時」「境界24時」を選べる。23時なら、入力か補正後が23時台のとき日柱を翌日にする（補正で前日に戻ったときは翌日にしない） | 24時のみ |
| 時刻不明 | 時柱なし。年柱・月柱は正午として節入りと比べる | 0時として比べる |
| 立運 | 生まれた日時から節入りまでの日数（時刻まで）÷3 を四捨五入、最低1歳 | 生まれた日の0時から数える |
| 蔵干 | 午＝丙・丁、酉＝庚・辛（前の月の本気を余気に入れる） | 午＝己・丁、酉＝辛のみ（**要確認：付録C Q28**） |

| 奇門遁甲：天禽 | 芮に添えて「芮禽」 | 表示なし |

### 一致した件数

- 命式：四柱と大運（立運と干支）が48件すべて一致（蔵干・五行は比べていない。2040年末の大運は節入りデータがなく出せない）
- 奇門遁甲：10盤すべて、9宮の天盤干・九星・地盤干・八門・八神が一致
- 五行の点数は、お手本がちょうど新版の10分の1（No.1 など）。お手本は計算方法を変えてあるため、大小の参考にとどめる
