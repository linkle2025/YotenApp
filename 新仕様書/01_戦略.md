# 1. 戦略（Strategy）

「誰の、どんな目的のためのアプリか」と「事業として何を狙うか」を決めます。以降のすべての判断の拠り所になります。

> 現行のコードとドキュメントから読み取れる範囲でまとめた叩き台です。「仮」の箇所は、[付録C_確認事項.md](./付録C_確認事項.md) で確定させてください。

---

## 1.1 プロダクトの位置づけ

**一文で言うと**：陽てん塾の四柱推命を、命式の根拠から「その人の強みと活かし方」まで、誰でもわかる言葉で示すアプリ。

現行（α版）で、すでに次の価値が形になっています。

1. **命式を正確に出す**：出生地による時刻補正、節入りによる月の切り替えなど、手計算では間違えやすい部分を自動化している。
2. **命式を現代の言葉に翻訳する**：鑑定スキル表で、9つの能力（企画・知略・実行・体力・人望・統率・開拓・商才・管理）と、7つの職種適性を点数とランクで示す。
3. **点数の理由を説明する**：判定の要点で、「なぜこの点数なのか」を日干を起点に AI が文章で説明する。読み方のルールは塾が設定ファイルで調整できる。

新版では、この3つを磨きつつ、**使いやすさ**と**集客の入口**を加えます。

## 1.2 利用者（ペルソナ）

現行の役割（ロール）と表示モードから想定した利用者です。

| # | 利用者 | 主な目的 | 現行での扱い | 確度 |
|---|---|---|---|---|
| A | **経営者**（自分や社員を知りたい） | 自分の強み・弱みを知る。社員の適材適所を考える。事業の悩みの理由を知る | 表示モード「経営者向け」。鑑定事例のSさん・Oさんがこの層 | 高 |
| B | **保護者**（子どもを知りたい） | 子どもの気質を知り、育て方・接し方のヒントを得る | 表示モード「保護者向け」。ただし表示は未実装 | 中（仮） |
| C | **占者・塾生**（鑑定する人） | 相談者の命式を素早く正確に出し、説明に使う | ロール「占者ユーザー」。ただし専用機能は未実装 | 中（仮） |
| D | **陽てん塾の運営者**（管理者） | 会員管理、解釈ルールの調整、奇門遁甲の作盤 | ロール「管理者」 | 高 |
| E | **はじめて訪れた人**（将来の集客対象） | 四柱推命や自分の性格に興味がある。気軽に試したい | 現行にはない（ログインしないと何も使えない） | 新規 |

### 利用者ごとの主な場面（仮）

- **A 経営者**：スマートフォンで自分の命式を開き、鑑定スキル表と判定の要点を読む。社員や採用候補の命式も作って比べる。塾の鑑定を受けた後に見返す。
- **B 保護者**：子どもの生年月日を入れ、気質と接し方のヒントを読む。経営者向けの職種適性の言葉はなじまない。
- **C 占者**：対面やオンラインの鑑定中に、相談者の命式をその場で出して画面を見せる。複数の相談者の記録を管理する。
- **D 運営者**：会員の状況を確認する。鑑定事例と本人の実感のズレを見て、解釈ルールを調整する。
- **E 初訪問者**：検索や SNS から紹介ページに来て、生年月日だけで無料診断を試す。結果の続きを見るために会員登録する。

## 1.3 利用者にとっての価値

| 利用者 | 解決したいこと | アプリが提供する価値 |
|---|---|---|
| A 経営者 | 「自分はなぜ管理が苦手なのか」「誰に何を任せるべきか」がわからない | 能力・職種の点数と、その理由の説明。活かし方の一言 |
| B 保護者 | 子どもの個性をどう伸ばせばよいかわからない | 気質の説明と、伸ばし方・接し方のヒント（要確認：内容は未定義） |
| C 占者 | 命式の計算に時間がかかる。説明の材料がほしい | 正確な命式を一瞬で出す。相談者に見せられる鑑定表 |
| D 運営者 | 鑑定の精度を上げたい。会員を管理したい | 解釈ルールの調整。会員と利用状況の把握 |
| E 初訪問者 | 自分の性格を手軽に知りたい | 登録なしで試せる無料診断と、わかりやすい読み物 |

## 1.4 事業としての狙い（仮）

1. **集客の入口になる**：検索に強い紹介ページ・読み物（十干・通変星の解説など）と無料診断で、塾を知らない人を呼び込む。
2. **会員化する**：無料診断の続き（鑑定スキル表の全体、判定の要点、記録の保存）を会員登録の動機にする。
3. **塾の鑑定・講座につなげる**：アプリでは「傾向」までを示し、深い相談は塾の鑑定や講座へ案内する（要確認：導線の有無と形）。
4. **運営の手間を減らす**：サーバー管理をなくし、解釈ルールなどは画面から調整できるようにする。

課金（有料会員、回数課金など）を入れるかどうかは未定です（[付録C](./付録C_確認事項.md)）。新版の最初のリリースでは課金を入れず、後から追加できる作りにしておきます。

## 1.5 成功の物差し（案）

| 区分 | 指標 | 目安（仮） |
|---|---|---|
| 正確さ | 正解データとの一致率（四柱・蔵干・通変星・格局） | 100%（不一致は流派の違いとして明記したものだけ） |
| 使いやすさ | 初めての人が、命式作成から鑑定表を見るまでの時間 | 1分以内（スマートフォン） |
| 使いやすさ | 判定の要点が表示され始めるまでの時間 | 5秒以内（文章は順に流れて表示） |
| 使いやすさ | 鑑定表の初回表示の速さ | スマートフォンの4G回線で2秒以内 |
| 集客 | 公開ページからの無料診断の利用数、無料診断から会員登録への転換率 | リリース後に基準値を測ってから決める |
| 継続 | 会員の月あたりの再訪率、1人あたりの鑑定記録数 | 同上 |
| 運営 | サーバー管理の作業時間 | ゼロ（OS・Nginx・Docker の管理をなくす） |

## 1.6 設計の原則

迷ったときは、次の順で判断します。

1. **正確さを最優先**：鑑定結果が間違っていれば、どんなに使いやすくても価値はない。正解データで照合できない計算は出さない。
2. **日干を起点に、理由まで伝える**：点数だけを見せず、「この日干の人にとって」という視点で、なぜそうなるのかを示す。
3. **断定せず、活かし方で終える**：「〜の傾向があります」と書く。運勢・吉凶の断定や、医療・法律・投資の助言はしない。低い項目も、補い方を添える。
4. **スマートフォンで迷わない**：主要な操作は片手で完結させる。入力は最小限にし、待ち時間には進み具合を見せる。
5. **個人情報を守る**：生年月日・出生時刻・出生地は個人情報として扱う。本人以外には見えないようにし、AI には氏名や生年月日を送らない。
6. **運営者が自分で直せる**：解釈ルールや説明文は、プログラムを書き換えずに調整できるようにする。

## 1.7 制約と前提

| 区分 | 内容 |
|---|---|
| 技術 | Next.js（App Router）＋Supabase（Auth・PostgreSQL）＋Vercel。サーバーの管理はしない |
| AI | Gemini API（有料枠のキーのみ。無料枠は入力が学習に使われる可能性があるため使わない） |
| 体制 | 少人数での開発・運営（推測）。運用の手間が少ないことを重視する |
| 費用 | 月額数千円〜1万円程度を想定（Vercel Pro、Supabase Pro、Gemini の従量課金。要確認） |
| 会員 | 既存会員は移行しない。新版で登録し直してもらう |
| 暦データ | 節入り時刻は 1901〜2040年。奇門遁甲の局数は現行 2026年分のみ |
| 法令 | 個人情報保護法への対応（利用目的の明示、第三者提供としての Gemini への送信の扱い、退会時の削除）。特定商取引法などは課金を入れる場合に必要 |

## 1.8 リリースの段階（案）

| 段階 | 内容 | 狙い |
|---|---|---|
| 0. 正解データ | お手本サイトと照合する正解データを作り、現行の計算を検証する | 正確さの基準を作る |
| 1. 新版の基本 | 現行と同じ機能を、新しい構成と使いやすい画面で提供する。既知の不具合を直す | 移行の完了。サーバー管理の廃止 |
| 2. 体験の向上 | 判定の要点の文字が順に流れる表示、本人コンテキストの入力、表示モードの中身、印刷・PDF | 会員の満足度を上げる |
| 3. 集客 | 紹介ページ、読み物、無料診断、SNS 共有用の画像 | 新しい会員を呼び込む |
| 4. 拡張 | 占者向け機能（相談者の管理など）、課金、解釈ルールの画面編集 | 事業の拡大 |

段階ごとの機能の詳細は [02_要件.md](./02_要件.md) にあります。
