# 時間不明機能の実装

## 概要

生まれた時間が不明な場合に対応するため、「時間不明」チェックボックスを追加しました。
チェックが入っている場合は、時柱を計算せず、空欄として表示します。

## 実装内容

### 1. フロントエンド

#### CalculatePage.js
- **チェックボックスの追加**
  - 「□時間不明」チェックボックスを追加
  - チェックが入っている場合、時間と分のプルダウンを無効化
  - `required` 属性を条件付きで適用

- **データ送信**
  - `hourUnknown` フラグをバックエンドに送信
  - 時間不明の場合も `birth_hour: 0`, `birth_minute: 0` を送信（DBの制約のため）

#### CalculatePage.css
- **チェックボックスのスタイリング**
  - `.checkbox-group` クラスを追加
  - チェックボックスとラベルを横並びに配置
  - カーソルをポインターに変更

#### DetailPage.css
- **時間不明マーカーのスタイリング**
  - `.unknown-marker` クラスを追加
  - 「ー」を灰色（#999）で表示
  - フォントウェイトは通常に設定

#### DetailPage.js
- **条件付き表示**
  - 時柱の列は常に表示
  - `hour_unknown` が `true` の場合、天干・地支・蔵干のセルに「ー」を表示
  - 生年月日の表示を「（時間不明）」に変更
  - 五行の背景色は適用しない

#### fortuneService.js
- **APIリクエストの更新**
  - `hour_unknown` パラメータを追加
  - リクエストペイロードに含めて送信

### 2. バックエンド

#### models.py
- **フィールドの追加**
  ```python
  hour_unknown = models.BooleanField(default=False, verbose_name='時間不明')
  ```

#### serializers.py
- **シリアライザの更新**
  - `FortuneCalculationSerializer` の `fields` に `hour_unknown` を追加
  - `FortuneCalculationListSerializer` の `fields` に `hour_unknown` を追加
  - `create` メソッドで `hour_unknown` を `calculate_fortune` に渡す
  - 時間不明の場合、時柱のフィールドを空文字列で保存

#### calculators.py
- **計算ロジックの更新**
  - `calculate_fortune` 関数に `hour_unknown` パラメータを追加
  - `hour_unknown=True` の場合、`hour_pillar` を `None` で返す
  - 時柱が `None` の場合、時柱関連の処理をスキップ
  - ログ出力を追加：「時柱: （時間不明のため計算なし）」

#### migrations/0007_fortunecalculation_hour_unknown.py
- **マイグレーションファイルの作成**
  - `hour_unknown` フィールドを追加するマイグレーション
  - デフォルト値: `False`

## 使用方法

### 1. マイグレーションの適用

```bash
cd /Users/ishikawa/Library/CloudStorage/Dropbox/cursor/YotenApp
docker-compose exec backend python manage.py migrate fortune
```

または

```bash
./apply_migrations.sh
```

### 2. 命式作成

1. `/calculate` ページにアクセス
2. 生年月日を入力
3. 時間が不明な場合は「□時間不明」にチェック
4. チェックを入れると、時間と分のプルダウンが無効化される
5. 都道府県、性別、氏名を入力
6. 「命式を作成」ボタンをクリック

### 3. 結果表示

- 時間不明の場合、詳細ページに「（時間不明）」と表示される
- 時柱の列は表示される
- 時柱の天干・地支・蔵干に「ー」が表示される
- 年柱、月柱、日柱は通常通り表示される

## データベース構造

### FortuneCalculation テーブル

| フィールド | 型 | デフォルト | 説明 |
|-----------|-----|-----------|------|
| birth_hour | IntegerField | - | 生時（時間不明の場合は0） |
| birth_minute | IntegerField | 0 | 生分（時間不明の場合は0） |
| hour_unknown | BooleanField | False | 時間不明フラグ |
| hour_pillar_heavenly_stem | CharField | '' | 時柱天干（時間不明の場合は空文字列） |
| hour_pillar_earthly_branch | CharField | '' | 時柱地支（時間不明の場合は空文字列） |
| ... | ... | ... | その他の時柱関連フィールドも同様 |

## テストケース

### 正常系

1. **時間が分かる場合**
   - チェックボックスをオフにする
   - 時間と分を選択できる
   - 時柱が正常に計算される
   - 詳細ページに時柱が表示される

2. **時間が不明な場合**
   - チェックボックスをオンにする
   - 時間と分のプルダウンが無効化される
   - 命式作成が正常に完了する
   - 詳細ページに「（時間不明）」と表示される
   - 時柱の列は表示される
   - 時柱の天干・地支・蔵干に「ー」が表示される

### 異常系

1. **既存データの互換性**
   - マイグレーション前のデータは `hour_unknown=False` として扱われる
   - 既存の命式は正常に表示される

2. **データ整合性**
   - `hour_unknown=True` の場合、時柱フィールドは空文字列
   - `hour_unknown=False` の場合、時柱フィールドは通常通り

## トラブルシューティング

### チェックボックスが表示されない
- ブラウザのキャッシュをクリア
- フロントエンドを再ビルド：`docker-compose restart frontend`

### 時柱が「ー」にならない
1. マイグレーションが適用されているか確認
   ```bash
   docker-compose exec backend python manage.py showmigrations fortune
   ```

2. バックエンドのログを確認
   ```bash
   docker-compose logs backend
   ```

3. データベースを確認
   ```bash
   docker-compose exec db psql -U yoten_user -d yoten_db -c "SELECT hour_unknown FROM fortune_fortunecalculation LIMIT 5;"
   ```

### 時柱の「ー」が表示されない
- フロントエンドのキャッシュをクリア
- ページをリロード（Cmd+Shift+R / Ctrl+Shift+R）
- ブラウザの開発者ツールでコンソールエラーを確認
