# 格局判定機能

## 概要

月支蔵干の透干状況を判定し、格局（食神格、傷官格、偏財格、正財格、偏官格、正官格、偏印格、印綬格）を自動判定して表示する機能です。

## 格局とは

格局（かっきょく）は、四柱推命において命式の基本的な性質を示す重要な指標です。月柱の地支（月支）の蔵干が、どの通変星として表れているかによって判定されます。

## 判定ルール

### ルール1: 本気が透干している場合

月支蔵干の**本気**が透干している場合、その本気の天干の通変星が格局となります。

**例**: 月支が寅（蔵干: 本気=甲、中気=丙、余気=戊）で、天干に甲または乙がある場合
- 甲の通変星が「偏印」なら → **偏印格**

### ルール2: 中気または余気が透干している場合

本気が透干しておらず、**中気**または**余気**のいずれかが透干している場合、その通変星が格局となります。

**例**: 月支が寅で、天干に丙または丁がある場合（甲は透干していない）
- 丙の通変星が「食神」なら → **食神格**

### ルール3: 余気と中気の両方が透干している場合

余気と中気の両方が透干している場合、**両方の格局を表示**します。

**表示形式**: 「◯格または◯格」

**例**: 月支が寅で、天干に丙（または丁）と戊（または己）の両方がある場合
- 丙の通変星が「食神」、戊の通変星が「偏財」なら → **食神格または偏財格**

### ルール4: どれも透干していない場合

本気・中気・余気のいずれも透干していない場合、**月支蔵干の本気の通変星**が格局となります。

**例**: 月支が寅で、天干に甲、乙、丙、丁、戊、己のいずれもない場合
- 本気の甲の通変星が「偏印」なら → **偏印格**

## 透干の定義

**透干（とうかん）**: 月支蔵干と**同じ五行**の天干が四柱の天干（年干・月干・日干・時干）のいずれかに存在すること

### 五行による透干判定

| 蔵干 | 五行 | 透干と判定される天干 |
|------|------|---------------------|
| 甲 | 木 | 甲、乙 |
| 乙 | 木 | 甲、乙 |
| 丙 | 火 | 丙、丁 |
| 丁 | 火 | 丙、丁 |
| 戊 | 土 | 戊、己 |
| 己 | 土 | 戊、己 |
| 庚 | 金 | 庚、辛 |
| 辛 | 金 | 庚、辛 |
| 壬 | 水 | 壬、癸 |
| 癸 | 水 | 壬、癸 |

### 例

月支が巳（本気=丙、中気=庚、余気=戊）の場合：

- 天干に「丙」または「丁」があれば → 本気（丙）が透干
- 天干に「庚」または「辛」があれば → 中気（庚）が透干
- 天干に「戊」または「己」があれば → 余気（戊）が透干

## 時間不明の場合

時間不明（hour_unknown = true）の場合、時干は透干の判定に**含まれません**。

判定対象の天干：**年干、月干、日干**のみ

## 格局の種類

格局として表示される可能性のある通変星：

| 通変星 | 格局名 |
|--------|--------|
| 食神 | 食神格 |
| 傷官 | 傷官格 |
| 偏財 | 偏財格 |
| 正財 | 正財格 |
| 偏官 | 偏官格 |
| 正官 | 正官格 |
| 偏印 | 偏印格 |
| 印綬 | 印綬格 |

**注**: 比肩と劫財は格局とはなりません。

## 実装詳細

### バックエンド (calculators.py)

#### calculate_kakukyoku()

```python
def calculate_kakukyoku(month_branch, year_stem, month_stem, day_stem, hour_stem, hour_unknown=False):
    """
    格局を判定
    
    Args:
        month_branch: 月柱の地支
        year_stem: 年柱の天干
        month_stem: 月柱の天干
        day_stem: 日柱の天干
        hour_stem: 時柱の天干（時間不明の場合はNone）
        hour_unknown: 時間不明フラグ
    
    Returns:
        str: 格局（例：「食神格」「傷官格または偏財格」等）
    """
```

**処理フロー**:
1. 月支の蔵干（本気・中気・余気）を取得
2. 天干リストを作成（時間不明の場合は時干を除外）
3. 各蔵干について透干判定（同じ五行の天干が存在するか）
4. ルール1〜4に従って格局を判定
5. 通変星から格名に変換して返す

#### calculate_fortune() の統合

```python
# 格局を判定
kakukyoku = calculate_kakukyoku(
    month_pillar['earthly_branch'],
    year_pillar['heavenly_stem'],
    month_pillar['heavenly_stem'],
    day_pillar['heavenly_stem'],
    hour_pillar['heavenly_stem'] if not hour_unknown else None,
    hour_unknown=hour_unknown
)

return {
    ...
    'kakukyoku': kakukyoku,
}
```

**テストデータ**: 月支が寅（本気=甲）、天干に甲がある

**期待結果**: 甲の通変星に応じた格局（例: 偏印格）

#### ケース2: 中気のみが透干している場合

**テストデータ**: 月支が寅（中気=丙）、天干に丙があるが甲はない

**期待結果**: 丙の通変星に応じた格局（例: 食神格）

#### ケース3: 余気と中気の両方が透干している場合

**テストデータ**: 月支が寅（中気=丙、余気=戊）、天干に丙と戊の両方がある

**期待結果**: 「◯格または◯格」形式（例: 食神格または偏財格）

#### ケース4: どれも透干していない場合

**テストデータ**: 月支が寅、天干に甲、乙、丙、丁、戊、己のいずれもない

**期待結果**: 本気の甲の通変星に応じた格局（例: 偏印格）

#### ケース5: 時間不明の場合

**テストデータ**: 時間不明、時干に透干する天干があるが、年干・月干・日干にはない

**期待結果**: 時干は無視され、ルール4が適用される

#### ケース6: 比肩・劫財の場合

**テストデータ**: 本気の通変星が比肩または劫財

**期待結果**: 格局なし（空欄または「-」）

## トラブルシューティング

### Q1: 格局が表示されない（空欄または「-」）

**原因**:
1. 本気の通変星が比肩または劫財
2. データベースの移行が完了していない
3. 計算エラー

**対処法**:
1. 比肩・劫財は格局にならないため正常
2. マイグレーションを実行: `docker-compose exec backend python manage.py migrate fortune`
3. バックエンドのログを確認: `docker-compose logs backend`

### Q2: 格局が間違っている気がする

**確認事項**:
1. 月支の蔵干が正しいか確認
2. 透干の定義（同じ五行）を確認
3. 時間不明の場合、時干が含まれていないか確認
4. バックエンドのログで格局判定の詳細を確認

**ログ確認コマンド**:
```bash
docker-compose logs backend | grep "格局判定"
```

### Q3: 古い命式で格局が表示されない

**原因**: マイグレーション前に作成された命式

**対処法**:
- 新しい命式を作成するか、古い命式を削除して再作成
