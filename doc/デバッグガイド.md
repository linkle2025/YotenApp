## ログレベルの変更

より詳細なログを見たい場合は、`backend/config/settings.py` のログレベルを変更してください：

```python
'loggers': {
    'apps.fortune.calculators': {
        'handlers': ['console'],
        'level': 'DEBUG',  # INFO → DEBUG に変更
        'propagate': False,
    },
    ...
}
```

変更後、コンテナを再起動：

```bash
docker-compose restart backend
```

## 確認すべきポイント

### 1. 時刻補正

- 経度差補正と均時差補正が正しく適用されているか
- 日付変更が必要な場合に正しく処理されているか

### 2. 節月判定

- 対象日時が正しく設定されているか
- 節気データが正しく読み込まれているか
- 最後に通過した節気が正しく判定されているか
- 節月番号が正しいか（1=寅月/立春、2=卯月/啓蟄、...、12=丑月/小寒）

### 3. 月柱計算

- 年柱の天干が正しいか
- 節月が正しいか
- 月柱天干の計算式が正しいか：`(年柱天干インデックス * 2 + 節月 - 1) % 10`
- 月柱地支の計算式が正しいか：`(節月 + 1) % 12`

## ログの保存

ログをファイルに保存したい場合：

```bash
docker-compose logs backend > debug_log_$(date +%Y%m%d_%H%M%S).txt
```

## トラブルシューティング

### ログが表示されない

1. コンテナが起動しているか確認：
```bash
docker-compose ps
```

2. ログレベルが適切か確認：
```bash
docker-compose exec backend python -c "from django.conf import settings; print(settings.LOGGING)"
```

3. コンテナを再起動：
```bash
docker-compose restart backend
```

### 文字化けが発生する場合

ターミナルのエンコーディングを確認：
```bash
export LANG=ja_JP.UTF-8
docker-compose logs -f backend
```
