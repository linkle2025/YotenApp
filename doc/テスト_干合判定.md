# 干合判定機能のテスト手順

## テスト目的

天干同士の干合が正しく判定され、適切に表示されることを確認する。

## テスト環境

- URL: http://localhost:3000
- ブラウザ: Chrome/Safari/Firefox

## 事前準備

```bash
# フロントエンドのキャッシュをクリア
Cmd+Shift+R (Mac) / Ctrl+Shift+R (Windows)

# バックエンドが起動していることを確認
docker-compose ps
```

## テストケース

### ケース1: 時柱と日柱の干合（戊+癸）

**テストデータ**:
- 生年月日時: 適当な日時で戊と癸が時柱と日柱になる命式

**手順**:
1. 命式の詳細ページを表示
2. 時柱の天干と日柱の天干を確認
3. 戊と癸の組み合わせであることを確認

**期待される結果**:
- [ ] 時柱の天干セルに金色のボーダー（9px solid gold）が表示される
- [ ] 日柱の天干セルに金色のボーダーが表示される
- [ ] ボーダーに金色の影（box-shadow）が適用される
- [ ] 命式テーブルの右下に「戊干と癸干が干合成立（時柱と日柱）」と表示される
- [ ] 表示文字が金色（#d4af37）で太字
- [ ] small文字で表示される

### ケース2: 日柱と月柱の干合（甲+己）

**テストデータ**:
- 日柱の天干: 甲
- 月柱の天干: 己

**期待される結果**:
- [ ] 日柱の天干セルに金色のボーダーが表示される
- [ ] 月柱の天干セルに金色のボーダーが表示される
- [ ] 「甲干と己干が干合成立（日柱と月柱）」と表示される

### ケース3: 月柱と年柱の干合（乙+庚）

**テストデータ**:
- 月柱の天干: 乙
- 年柱の天干: 庚

**期待される結果**:
- [ ] 月柱の天干セルに金色のボーダーが表示される
- [ ] 年柱の天干セルに金色のボーダーが表示される
- [ ] 「乙干と庚干が干合成立（月柱と年柱）」と表示される

### ケース4: 複数の干合が同時に成立

**テストデータ**:
- 時柱: 甲
- 日柱: 己（甲+己で干合）
- 月柱: 丙
- 年柱: 辛（丙+辛で干合）

**期待される結果**:
- [ ] 時柱の天干セルに金色のボーダー
- [ ] 日柱の天干セルに金色のボーダー
- [ ] 月柱の天干セルに金色のボーダー
- [ ] 年柱の天干セルに金色のボーダー
- [ ] 「甲干と己干が干合成立（時柱と日柱）」と表示
- [ ] 「丙干と辛干が干合成立（月柱と年柱）」と表示
- [ ] 2つの干合情報が縦に並んで表示される

### ケース5: 干合が成立しない場合

**テストデータ**:
- 時柱: 甲
- 日柱: 乙
- 月柱: 丙
- 年柱: 丁

**期待される結果**:
- [ ] すべての天干セルに金色のボーダーなし
- [ ] 干合の表示なし
- [ ] 通常の五行の背景色のみ表示

### ケース6: 時柱と年柱で干合の組み合わせがある場合

**テストデータ**:
- 時柱: 丁
- 日柱: 乙
- 月柱: 丙
- 年柱: 壬（丁+壬の組み合わせだが隣接していない）

**期待される結果**:
- [ ] 時柱と年柱には金色のボーダーなし
- [ ] 干合の表示なし
- [ ] 隣接していないため判定されない

### ケース7: 時間不明の場合

**テストデータ**:
- 時柱: （時間不明）
- 日柱: 戊
- 月柱: 癸
- 年柱: 甲

**期待される結果**:
- [ ] 時柱は「ー」表示
- [ ] 日柱の天干セルに金色のボーダー
- [ ] 月柱の天干セルに金色のボーダー
- [ ] 「戊干と癸干が干合成立（日柱と月柱）」と表示
- [ ] 時柱は判定対象外
