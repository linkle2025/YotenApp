# 五行バランス 身旺・身弱の自動判定機能

## 概要

五行バランス表において、左上と右下の点数を自動計算し、それに基づいて身旺・身弱を自動判定する機能を実装しました。

## 計算ロジック

### 左上の点数

**計算式**: 自分の五行の点数 + 左の五行（偏印・印綬）の点数

```
左上の点数 = 上（中央上）の五行 + 左の五行
```

- **上（中央上）**: 日干の五行（自分自身）
- **左**: 偏印・印綬の五行

### 右下の点数

**計算式**: 右の五行（食傷星）+ 下右の五行（財星）+ 下左の五行（官星）

```
右下の点数 = 右の五行 + 下右の五行 + 下左の五行
```

- **右**: 食傷星の五行
- **下右**: 財星の五行
- **下左**: 官星の五行

### 五行の配置

五行は日干を基準に時計回りに配置されます：

```
         [上]
         自分
    [左]     [右]
   印綬     食傷
     [下左][下右]
     官星  財星
```

## 身旺・身弱の判定

計算された左上と右下の点数を比較して判定します：

| 条件 | 判定結果 |
|------|---------|
| 左上 > 右下 | **身旺** |
| 左上 < 右下 | **身弱** |
| 左上 = 右下 | **-** |

### 判定の意味

- **身旺（しんおう）**: 自分（日干）のエネルギーが強い状態。自分を生み助ける五行が多い。
- **身弱（しんじゃく）**: 自分（日干）のエネルギーが弱い状態。自分を剋し漏らす五行が多い。
- **-（中和）**: 左右のバランスが取れている状態。

## 実装詳細

### フロントエンド (DetailPage.js)

#### 新規追加関数

1. **calculateTopLeftScore()**
   - 左上の点数を計算
   - 戻り値: number（小数点含む）

```javascript
const calculateTopLeftScore = () => {
  if (!calculation || !calculation.five_elements_balance_data) return 0;
  
  const orderedElements = getOrderedElements();
  const scores = calculation.five_elements_balance_data.scores || {};
  
  // positions[0]: 上（自分の五行）
  // positions[4]: 左（偏印・印綬）
  const topElement = orderedElements[0]?.element;
  const leftElement = orderedElements[4]?.element;
  
  const topScore = scores[topElement] || 0;
  const leftScore = scores[leftElement] || 0;
  
  return topScore + leftScore;
};
```

2. **calculateBottomRightScore()**
   - 右下の点数を計算
   - 戻り値: number（小数点含む）

```javascript
const calculateBottomRightScore = () => {
  if (!calculation || !calculation.five_elements_balance_data) return 0;
  
  const orderedElements = getOrderedElements();
  const scores = calculation.five_elements_balance_data.scores || {};
  
  // positions[1]: 右（食傷星）
  // positions[2]: 下右（財星）
  // positions[3]: 下左（官星）
  const rightElement = orderedElements[1]?.element;
  const bottomRightElement = orderedElements[2]?.element;
  const bottomLeftElement = orderedElements[3]?.element;
  
  const rightScore = scores[rightElement] || 0;
  const bottomRightElementScore = scores[bottomRightElement] || 0;
  const bottomLeftElementScore = scores[bottomLeftElement] || 0;
  
  return rightScore + bottomRightElementScore + bottomLeftElementScore;
};
```

3. **getStrengthLabel()**
   - 身旺・身弱を判定
   - 戻り値: string（'身旺' | '身弱' | '-'）

```javascript
const getStrengthLabel = () => {
  const topLeftScore = calculateTopLeftScore();
  const bottomRightScore = calculateBottomRightScore();
  
  if (topLeftScore > bottomRightScore) {
    return '身旺';
  } else if (topLeftScore < bottomRightScore) {
    return '身弱';
  } else {
    return '-';
  }
};
```

#### 表示の変更

**修正前**:
```jsx
{/* 固定値 */}
<div className="score-value">55</div>
<div className="score-value">37.5</div>
<div className="summary-label">身旺</div>
```

**修正後**:
```jsx
{/* 動的に計算 */}
<div className="score-value">{calculateTopLeftScore().toFixed(1)}</div>
<div className="score-value">{calculateBottomRightScore().toFixed(1)}</div>
<div className="summary-label">{getStrengthLabel()}</div>
```

## テスト方法

### 1. 準備

ブラウザで http://localhost:3000 にアクセスし、命式を作成または表示します。

### 2. 確認項目

#### 基本動作
- [ ] 左上の点数が動的に計算されて表示される
- [ ] 右下の点数が動的に計算されて表示される
- [ ] 身旺/身弱/- が正しく判定される
- [ ] 点数は小数点1桁で表示される

#### 判定パターン

**パターン1: 身旺のケース**
- 期待: 左上 > 右下
- 表示: 「身旺」

**パターン2: 身弱のケース**
- 期待: 左上 < 右下
- 表示: 「身弱」

**パターン3: 中和のケース**
- 期待: 左上 = 右下
- 表示: 「-」

### 3. 計算検証

デバッグ情報を確認して、各五行の点数を検証：

1. 鑑定表ページの五行バランスセクション下部に「計算デバッグ情報」が表示される
2. 各五行の最終点数を確認
3. 手動で左上と右下の点数を計算
4. 表示されている点数と一致することを確認

### 4. エッジケース

#### ケース1: 時間不明
- 時柱がない場合でも正しく計算される
- 天干が3つのみで判定される

#### ケース2: 極端な偏り
- 特定の五行が0点の場合でも正常に動作
- 一つの五行が非常に高い点数でも正常に表示

#### ケース3: 古いデータ
- `five_elements_balance_data` がない場合、0点として扱う
- エラーが発生せず、0.0と表示される

## 使用例

### 例1: 身旺の命式

```
日干: 甲（木）

五行の点数:
- 木（自分）: 20.0
- 火: 15.0
- 土: 10.0
- 金: 5.0
- 水（印綬）: 25.0

配置:
        木（20.0）
   水（25.0）  火（15.0）
      金（5.0）土（10.0）

左上 = 木 + 水 = 20.0 + 25.0 = 45.0
右下 = 火 + 土 + 金 = 15.0 + 10.0 + 5.0 = 30.0

判定: 45.0 > 30.0 → 身旺
```

### 例2: 身弱の命式

```
日干: 丙（火）

五行の点数:
- 火（自分）: 10.0
- 土: 20.0
- 金: 15.0
- 水: 5.0
- 木（印綬）: 15.0

配置:
        火（10.0）
   木（15.0）  土（20.0）
      水（5.0）金（15.0）

左上 = 火 + 木 = 10.0 + 15.0 = 25.0
右下 = 土 + 金 + 水 = 20.0 + 15.0 + 5.0 = 40.0

判定: 25.0 < 40.0 → 身弱
```

## 参考

### 四柱推命の基礎理論

- **身旺**: 日干のエネルギーが強い状態。比肩・劫財（自分と同じ五行）、偏印・印綬（自分を生む五行）が多い。
- **身弱**: 日干のエネルギーが弱い状態。食神・傷官（自分が生む五行）、偏財・正財（自分が剋す五行）、偏官・正官（自分を剋す五行）が多い。

| 上（自分） | 日干 | 比肩・劫財 |
| 左 | 自分を生む | 偏印・印綬 |
| 右 | 自分が生む | 食神・傷官 |
| 下右 | 自分が剋す | 偏財・正財 |

## トラブルシューティング

### Q1: 点数が0.0と表示される

**原因**: バックエンドで五行バランス計算が実行されていない

**対処法**:
1. マイグレーションが適用されているか確認
2. バックエンドを再起動
3. 新しい命式を作成

### Q2: 身旺/身弱が正しくない気がする

**対処法**:
1. デバッグ情報で各五行の点数を確認
2. 月令、死令、天干の有無による補正を確認
3. 計算ロジックを手動で検証

### Q3: 古い命式で点数が表示されない

**対処法**:
- 古い命式を削除して新規作成
- または、バックエンドで再計算機能を追加（今後の拡張）
