## 概要

### 四柱推命とは

四柱推命は、生年月日時の4つの時間軸（年・月・日・時）から、それぞれの「柱」を算出し、その人の性格や運勢を占う中国古来の占術です。

### 対応年範囲

本アプリケーションは、**1901年から2040年までの生年月日**に対応しています。この範囲では、万年暦に基づく正確な節気日時データと日柱データを使用して計算を行います。

- **対応年範囲：1901年～2040年**
- この範囲外の年については、現在のバージョンでは計算できません（エラーが発生します）

### 十干（じっかん）

天の気を表す10種類の要素：

| 順番 | 干 | 読み | 五行 | 陰陽 |
|------|-----|------|------|------|
| 1 | 甲 | きのえ | 木 | 陽 |
| 2 | 乙 | きのと | 木 | 陰 |
| 3 | 丙 | ひのえ | 火 | 陽 |
| 4 | 丁 | ひのと | 火 | 陰 |
| 5 | 戊 | つちのえ | 土 | 陽 |
| 6 | 己 | つちのと | 土 | 陰 |
| 7 | 庚 | かのえ | 金 | 陽 |
| 8 | 辛 | かのと | 金 | 陰 |
| 9 | 壬 | みずのえ | 水 | 陽 |
| 10 | 癸 | みずのと | 水 | 陰 |

### 十二支（じゅうにし）

地の気を表す12種類の要素：

| 順番 | 支 | 読み | 方角 | 時刻 |
|------|-----|------|------|------|
| 1 | 子 | ね | 北 | 23-1時 |
| 2 | 丑 | うし | 北北東 | 1-3時 |
| 3 | 寅 | とら | 東北東 | 3-5時 |
| 4 | 卯 | う | 東 | 5-7時 |
| 5 | 辰 | たつ | 東南東 | 7-9時 |
| 6 | 巳 | み | 南南東 | 9-11時 |
| 7 | 午 | うま | 南 | 11-13時 |
| 8 | 未 | ひつじ | 南南西 | 13-15時 |
| 9 | 申 | さる | 西南西 | 15-17時 |
| 10 | 酉 | とり | 西 | 17-19時 |
| 11 | 戌 | いぬ | 西北西 | 19-21時 |
| 12 | 亥 | い | 北北西 | 21-23時 |

### 60干支周期

十干（10種類）と十二支（12種類）を組み合わせると、60通りの組み合わせができます。これを60干支といい、年・月・日・時はそれぞれこの60干支の周期で循環します。

最小公倍数: LCM(10, 12) = 60

例：
- 1番目: 甲子（きのえね）
- 2番目: 乙丑（きのとうし）
- ...
- 60番目: 癸亥（みずのとい）
- 61番目: 甲子（最初に戻る）

## 時刻補正ロジック

四柱推命の計算において、正確な太陽時を使用する必要があります。本アプリケーションでは、以下の2つの補正を適用します。

### 都道府県の経度差補正

#### 概念

日本の標準時は東経135度（兵庫県明石市）を基準としていますが、実際の各地の経度は異なります。経度1度の差は約4分の時差に相当するため、生まれた場所によって時刻を補正する必要があります。

#### 計算式

```
経度差による補正時間（分） = (実際の経度 - 135度) × 4分/度
```

本アプリケーションでは、各都道府県の代表的な経度を基に、あらかじめ計算された補正値を使用します。

#### 都道府県別補正値（一部抜粋）

| 都道府県 | 補正値（分） | 説明 |
|---------|-------------|------|
| 北海道 | +25 | 東側（標準時より早い） |
| 東京都 | +19 | 東側 |
| 兵庫県 | 0 | 標準時子午線 |
| 大阪府 | +2 | やや東側 |
| 広島県 | -10 | 西側（標準時より遅い） |
| 福岡県 | -18 | 西側 |
| 沖縄県 | -29 | 最も西側 |

**全47都道府県の補正値は `backend/apps/fortune/calculators.py` の `PREFECTURE_TIME_OFFSETS` を参照してください。**

#### 具体例

**例1: 東京都で10時0分生まれ**
```
補正時間 = 10時0分 + 19分 = 10時19分
```

**例2: 沖縄県で10時0分生まれ**
```
補正時間 = 10時0分 - 29分 = 9時31分
```

### 均時差補正

#### 概念

均時差（Equation of Time）とは、真太陽時と平均太陽時のずれのことです。地球の公転軌道が楕円であることと、地軸が傾いていることにより、実際の太陽の動きと平均的な時刻の間にずれが生じます。

このずれは季節によって異なり、最大で±16分程度になります。

#### 月別均時差

| 月 | 均時差（分） | 説明 |
|----|-------------|------|
| 1月 | -3 | マイナス補正 |
| 2月 | -13 | 年間最大のマイナス補正 |
| 3月 | -12 | マイナス補正 |
| 4月 | -4 | マイナス補正 |
| 5月 | +3 | プラス補正 |
| 6月 | +2 | プラス補正 |
| 7月 | -3 | マイナス補正 |
| 8月 | -6 | マイナス補正 |
| 9月 | 0 | 補正なし |
| 10月 | +10 | プラス補正 |
| 11月 | +16 | 年間最大のプラス補正 |
| 12月 | +11 | プラス補正 |

#### 具体例

**例1: 1月、10時0分生まれ**
```
均時差補正 = 10時0分 - 3分 = 9時57分
```

**例2: 11月、10時0分生まれ**
```
均時差補正 = 10時0分 + 16分 = 10時16分
```

### 統合補正の計算

実際の計算では、都道府県の経度差と均時差の両方を同時に適用します。

#### 計算式

```python
補正後の時刻（分単位） = 元の時刻（分） + 都道府県補正（分） + 均時差（分）
```

#### 日付変更の処理

補正の結果、時刻が0時より前または24時以降になる場合、日付を変更します。

```python
if 補正後の時刻 < 0:
    # 前日になる
    日付 = 日付 - 1日
    時刻 = 時刻 + 24時間
elif 補正後の時刻 >= 24時間:
    # 翌日になる
    日付 = 日付 + 1日
    時刻 = 時刻 - 24時間
```

#### 統合補正の具体例

**例1: 東京都、1月、10時0分生まれ**
```
都道府県補正: +19分
均時差補正: -3分
合計補正: +16分
補正後: 10時16分（同日）
```

**例2: 沖縄県、2月、10時0分生まれ**
```
都道府県補正: -29分
均時差補正: -13分
合計補正: -42分
補正後: 9時18分（同日）
```

**例3: 北海道、11月、23時50分生まれ**
```
都道府県補正: +25分
均時差補正: +16分
合計補正: +41分
補正前: 23時50分 = 1430分
補正後: 1471分 = 24時31分
→ 日付変更: 翌日 0時31分
```

**例4: 沖縄県、2月、0時10分生まれ**
```
都道府県補正: -29分
均時差補正: -13分
合計補正: -42分
補正前: 0時10分 = 10分
補正後: -32分
→ 日付変更: 前日 23時28分
```

## 年柱の計算

年柱は生まれた年の干支を表します。

### 計算方法

#### 基準年

1984年を甲子年（60干支周期の1番目）として基準とします。

#### 計算式

```python
# 1. 基準年からのオフセットを計算
offset = (生年 - 1984) % 60

# 2. 天干のインデックスを計算
heavenly_stem_index = offset % 10

# 3. 地支のインデックスを計算
earthly_branch_index = offset % 12

# 4. インデックスから干支を取得
年柱の天干 = HEAVENLY_STEMS[heavenly_stem_index]
年柱の地支 = EARTHLY_BRANCHES[earthly_branch_index]
```

### 具体例

#### 例1: 1990年生まれ

```
1. オフセット計算
   offset = (1990 - 1984) % 60 = 6 % 60 = 6

2. 天干のインデックス
   heavenly_stem_index = 6 % 10 = 6
   → HEAVENLY_STEMS[6] = '庚'（かのえ）

3. 地支のインデックス
   earthly_branch_index = 6 % 12 = 6
   → EARTHLY_BRANCHES[6] = '午'（うま）

結果: 1990年 = 庚午（かのえうま）
```

#### 例2: 2000年生まれ

```
1. オフセット計算
   offset = (2000 - 1984) % 60 = 16 % 60 = 16

2. 天干のインデックス
   heavenly_stem_index = 16 % 10 = 6
   → HEAVENLY_STEMS[6] = '庚'（かのえ）

3. 地支のインデックス
   earthly_branch_index = 16 % 12 = 4
   → EARTHLY_BRANCHES[4] = '辰'（たつ）

結果: 2000年 = 庚辰（かのえたつ）
```

#### 例3: 2024年生まれ

```
1. オフセット計算
   offset = (2024 - 1984) % 60 = 40 % 60 = 40

2. 天干のインデックス
   heavenly_stem_index = 40 % 10 = 0
   → HEAVENLY_STEMS[0] = '甲'（きのえ）

3. 地支のインデックス
   earthly_branch_index = 40 % 12 = 4
   → EARTHLY_BRANCHES[4] = '辰'（たつ）

結果: 2024年 = 甲辰（きのえたつ）
```

## 月柱の計算

月柱は生まれた月の干支を表します。四柱推命では、通常の暦月ではなく「節月」を使用します。

### 節月の概念

#### 節月とは

節月は24節気の「節」を基準とした月の区切りで、立春から始まります。

#### 節気の日時データ

本アプリケーションでは、1901年から2040年までの正確な節気日時データを使用します。このデータは万年暦に基づいており、各節気の入り時刻（年・月・日・時・分）が記録されています。

| 節月 | 節気 | 対応する暦月 |
|------|------|-------------|
| 1月（寅月） | 立春 | 2月前半 |
| 2月（卯月） | 啓蟄 | 3月前半 |
| 3月（辰月） | 清明 | 4月前半 |
| 4月（巳月） | 立夏 | 5月前半 |
| 5月（午月） | 芒種 | 6月前半 |
| 6月（未月） | 小暑 | 7月前半 |
| 7月（申月） | 立秋 | 8月前半 |
| 8月（酉月） | 白露 | 9月前半 |
| 9月（戌月） | 寒露 | 10月前半 |
| 10月（亥月） | 立冬 | 11月前半 |
| 11月（子月） | 大雪 | 12月前半 |
| 12月（丑月） | 小寒 | 1月前半 |

**対応年範囲：1901年～2040年**

この範囲外の年については、現在のバージョンでは計算できません。

#### 節月の決定ロジック

1. 指定された生年月日時（時刻補正後）をdatetimeオブジェクトに変換
2. 節気データから該当年の全節気をロード
3. 指定日時以前で最も近い節気を探す
4. その節気に対応する節月が、その日の節月となる

```python
def get_solar_month(year, month, day, hour=0, minute=0):
    # 指定された日時をdatetimeオブジェクトに変換
    target_dt = datetime(year, month, day, hour, minute)
    
    # 年内の全節気を取得してソート
    # 対象日時がどの節月に属するかを判定
    # 最後に通過した節気の月が現在の節月
```

### 計算方法

月柱の干支は、**節気データから直接取得**します。

#### 取得方法

```python
# 1. 指定された日時をdatetimeオブジェクトに変換
target_dt = datetime(year, month, day, hour, minute)

# 2. 年内の全節気を取得してソート
# 各節気データには以下が含まれる:
# - date: 節気の日付
# - hour, minute: 節気の時刻
# - term: 節気名（例: "立夏"）
# - month_pillar: 月干支（例: "辛巳"）← これを使用！
# - day_pillar: 日干支

# 3. 対象日時以前で最も近い節気を探す
for term_info in sorted_terms:
    if target_dt >= term_info['datetime']:
        current_month_pillar = term_info['month_pillar']
        
# 4. 月干支を天干と地支に分割
月柱の天干 = current_month_pillar[0]  # 例: "辛"
月柱の地支 = current_month_pillar[1]  # 例: "巳"
```

**重要**: 月柱の天干は計算式では正確に求められないため、節気データに含まれる月干支をそのまま使用します。

### 具体例

#### 例1: 1985年5月10日 11時30分（岐阜県）生まれ

```
1. 時刻補正
   入力時刻: 11時30分
   岐阜県の経度差補正: +7分
   5月の均時差: +3分
   補正後時刻: 11時40分

2. 対象日時
   1985年5月10日 11時40分

3. 節気データの検索
   年内の節気を確認:
   - 小寒: 1985-01-05 18:36 (月柱: 丁丑)
   - 立春: 1985-02-04 06:13 (月柱: 戊寅)
   - 啓蟄: 1985-03-06 00:18 (月柱: 己卯)
   - 清明: 1985-04-05 05:14 (月柱: 庚辰)
   - 立夏: 1985-05-05 22:43 (月柱: 辛巳) ← 最後に通過した節気
   - 芒種: 1985-06-06 03:00 (月柱: 壬午)

4. 月柱の決定
   最後に通過した節気: 立夏 (1985-05-05 22:43)
   その節気の月柱: 辛巳
   
結果: 月柱 = 辛巳（かのとみ）
```

**注**: カレンダーの5月ですが、節月は4月（巳月）になります。


## 日柱の計算

日柱は生まれた日の干支を表します。

### 計算方法

本アプリケーションでは、1901年から2040年までの正確な万年暦データを使用して日柱を計算します。

**対応年範囲：1901年～2040年**

#### 計算手順

1. 対象日をdatetimeオブジェクトに変換
2. 節気データから対象日以前で最も近い節気を探す
3. その節気の日干支を基準として、日数差分から対象日の日干支を計算

```python
def calculate_day_pillar(year, month, day):
    # 対象日をdatetimeオブジェクトに変換
target_date = datetime(year, month, day)

    # 年内の全節気を取得し、最も近い節気の日干支を基準とする
    closest_term = find_closest_solar_term(target_date)
    
    # 基準となる節気の日干支を取得
    base_day_pillar = closest_term['day_pillar']
    
    # 日数差分だけ干支を進める（60日周期）
    days_diff = (target_date - closest_term['date']).days
    new_stem_index = (base_stem_index + days_diff) % 10
    new_branch_index = (base_branch_index + days_diff) % 12
```

この方法により、万年暦に基づく正確な日柱計算が実現されます。

### 具体例

#### 例1: 1990年1月1日

```
1. 基準日: 1900年1月1日
   対象日: 1990年1月1日

2. 経過日数の計算
   days_diff = 90年間 = 32,873日
   （うるう年を含む正確な日数）

3. 60日周期のオフセット
   offset = 32,873 % 60 = 53

4. 天干のインデックス
   heavenly_stem_index = 53 % 10 = 3
   → HEAVENLY_STEMS[3] = '丁'（ひのと）

5. 地支のインデックス
   earthly_branch_index = 53 % 12 = 5
   → EARTHLY_BRANCHES[5] = '巳'（み）

結果: 日柱 = 丁巳（ひのとみ）
```

#### 例2: 2000年1月1日

```
1. 経過日数
   days_diff = (2000年1月1日 - 1900年1月1日).days
             = 36,524日

2. オフセット
   offset = 36,524 % 60 = 4

3. 天干のインデックス
   heavenly_stem_index = 4 % 10 = 4
   → HEAVENLY_STEMS[4] = '戊'（つちのえ）

4. 地支のインデックス
   earthly_branch_index = 4 % 12 = 4
   → EARTHLY_BRANCHES[4] = '辰'（たつ）

結果: 日柱 = 戊辰（つちのえたつ）
```

## 時柱の計算

時柱は生まれた時刻の干支を表します。

### 時刻と地支の対応

時柱の地支は、生まれた時刻によって決まります（2時間単位）：

| 時刻 | 地支 | インデックス |
|------|------|-------------|
| 23時-1時 | 子（ね） | 0 |
| 1時-3時 | 丑（うし） | 1 |
| 3時-5時 | 寅（とら） | 2 |
| 5時-7時 | 卯（う） | 3 |
| 7時-9時 | 辰（たつ） | 4 |
| 9時-11時 | 巳（み） | 5 |
| 11時-13時 | 午（うま） | 6 |
| 13時-15時 | 未（ひつじ） | 7 |
| 15時-17時 | 申（さる） | 8 |
| 17時-19時 | 酉（とり） | 9 |
| 19時-21時 | 戌（いぬ） | 10 |
| 21時-23時 | 亥（い） | 11 |

### 計算方法

#### 計算式

```python
# 1. 日柱の天干のインデックスを取得
day_stem_index = HEAVENLY_STEMS.index(日柱の天干)

# 2. 時柱の地支を計算（時刻から）
hour_branch_index = ((hour + 1) // 2) % 12
時柱の地支 = EARTHLY_BRANCHES[hour_branch_index]

# 3. 時柱の天干を計算（日柱の天干と時柱の地支から）
hour_stem_index = (day_stem_index * 2 + hour_branch_index) % 10
時柱の天干 = HEAVENLY_STEMS[hour_stem_index]
```

#### 地支計算の詳細

時刻を地支のインデックスに変換する計算：

```python
hour_branch_index = ((hour + 1) // 2) % 12
```

この式の意味：
- `hour + 1`: 23時を子時（0番目）にするためのオフセット
- `// 2`: 2時間単位で割る（整数除算）
- `% 12`: 12支の範囲に収める

例：
- hour=0 → (0+1)//2 = 0 → 子
- hour=1 → (1+1)//2 = 1 → 丑
- hour=10 → (10+1)//2 = 5 → 巳
- hour=23 → (23+1)//2 = 12 % 12 = 0 → 子

### 具体例

#### 例1: 10時、日柱が丁巳の場合

```
1. 日柱の天干のインデックス
   丁のインデックス = 3

2. 時柱の地支を計算
   hour_branch_index = ((10 + 1) // 2) % 12
                     = (11 // 2) % 12
                     = 5 % 12
                     = 5
   → EARTHLY_BRANCHES[5] = '巳'（み）

3. 時柱の天干を計算
   hour_stem_index = (3 * 2 + 5) % 10
                   = (6 + 5) % 10
                   = 11 % 10
                   = 1
   → HEAVENLY_STEMS[1] = '乙'（きのと）

結果: 時柱 = 乙巳（きのとみ）
```

#### 例2: 23時、日柱が戊辰の場合

```
1. 日柱の天干のインデックス
   戊のインデックス = 4

2. 時柱の地支を計算
   hour_branch_index = ((23 + 1) // 2) % 12
                     = (24 // 2) % 12
                     = 12 % 12
                     = 0
   → EARTHLY_BRANCHES[0] = '子'（ね）

3. 時柱の天干を計算
   hour_stem_index = (4 * 2 + 0) % 10
                   = 8 % 10
                   = 8
   → HEAVENLY_STEMS[8] = '壬'（みずのえ）

結果: 時柱 = 壬子（みずのえね）
```

#### 例3: 時刻補正を含む計算

**前提**: 東京都、1月、10時0分生まれ

```
1. 時刻補正
   都道府県補正: +19分
   均時差補正: -3分
   合計補正: +16分
   補正後の時刻: 10時16分 → 時柱計算には10時を使用

2. 時柱の地支（補正後の時刻で計算）
   hour_branch_index = ((10 + 1) // 2) % 12 = 5
   → '巳'（み）

3. 時柱の天干（日柱によって決まる）
   日柱が丁巳の場合:
   hour_stem_index = (3 * 2 + 5) % 10 = 1
   → '乙'（きのと）

結果: 時柱 = 乙巳（きのとみ）
```

## 完全な計算フローの例

ここでは、具体的な生年月日時での四柱推命の全計算過程を示します。

### 例: 1990年1月1日10時0分、東京都生まれ

#### ステップ1: 時刻補正

```
生まれた時刻: 10時0分
生まれた月: 1月
生まれた都道府県: 東京都

1. 都道府県の経度差補正
   東京都の補正値: +19分

2. 均時差補正
   1月の均時差: -3分

3. 統合補正
   合計補正 = +19分 + (-3分) = +16分
   補正後の時刻 = 10時0分 + 16分 = 10時16分

4. 日付変更の判定
   10時16分は0-24時の範囲内 → 日付変更なし

補正後の生年月日時: 1990年1月1日10時16分
```

#### ステップ2: 年柱の計算

```
生年: 1990年

1. オフセット
   offset = (1990 - 1984) % 60 = 6

2. 天干
   heavenly_stem_index = 6 % 10 = 6
   → '庚'（かのえ）

3. 地支
   earthly_branch_index = 6 % 12 = 6
   → '午'（うま）

年柱 = 庚午（かのえうま）
```

#### ステップ3: 月柱の計算

```
生年月日: 1990年1月1日

1. 節月の決定
   暦月 = 1月、日 = 1日
   1日 < 6日 → 節月 = 12月（前年）

2. 年柱の天干のインデックス
   庚のインデックス = 6

3. 月柱の天干
   month_stem_index = (6 * 2 + 12 - 1) % 10
                    = 23 % 10
                    = 3
   → '丁'（ひのと）

4. 月柱の地支
   month_branch_index = (12 + 1) % 12 = 1
   → '丑'（うし）

月柱 = 丁丑（ひのとうし）
```

#### ステップ4: 日柱の計算

```
生年月日: 1990年1月1日

1. 経過日数
   base_date = 1900年1月1日
   target_date = 1990年1月1日
   days_diff = 32,873日

2. オフセット
   offset = 32,873 % 60 = 53

3. 天干
   heavenly_stem_index = 53 % 10 = 3
   → '丁'（ひのと）

4. 地支
   earthly_branch_index = 53 % 12 = 5
   → '巳'（み）

日柱 = 丁巳（ひのとみ）
```

#### ステップ5: 時柱の計算

```
補正後の時刻: 10時16分（時柱計算には10時を使用）
日柱: 丁巳

1. 日柱の天干のインデックス
   丁のインデックス = 3

2. 時柱の地支
   hour_branch_index = ((10 + 1) // 2) % 12
                     = 5
   → '巳'（み）

3. 時柱の天干
   hour_stem_index = (3 * 2 + 5) % 10
                   = 11 % 10
                   = 1
   → '乙'（きのと）

時柱 = 乙巳（きのとみ）
```

#### 最終結果

**生年月日時**: 1990年1月1日10時0分、東京都生まれ

**四柱**:
- **年柱**: 庚午（かのえうま）
- **月柱**: 丁丑（ひのとうし）
- **日柱**: 丁巳（ひのとみ）
- **時柱**: 乙巳（きのとみ）

## 注意事項

### 正確なデータの使用

本アプリケーション（バージョン2.0以降）では、以下の正確なデータを使用しています：

#### 1. 節月の決定

- **本実装**: 万年暦に基づく正確な節気日時データを使用（1901-2040年）
- 各年の正確な節気の入り時刻（年・月・日・時・分）を参照
- 時刻補正（経度差・均時差）も考慮した上で節月を判定

#### 2. 日柱の計算

- **本実装**: 万年暦に基づく正確な日干支データを使用（1901-2040年）
- 節気データに含まれる日干支を基準として計算
- 正確な60干支周期を考慮

#### 3. 対応年範囲の制限

- **対応年範囲**: 1901年～2040年
- この範囲外の年については計算できません（エラーが発生します）
- 範囲内では、伝統的な万年暦と同等の精度を持ちます

### 簡易版の実装（対応年範囲内）

以下の点では、簡易的な実装を採用しています：

#### 月柱・時柱の天干計算

- **本実装**: 簡易的な数式を使用
- **正式な方法**: より複雑な対応表を使用

本実装の計算式は一般的な傾向を表していますが、流派によっては異なる場合があります。

### 実際の四柱推命との相違点

#### 使用目的の違い

- **本アプリケーション**: 四柱推命の基本的な仕組みを理解し、おおよその命式を知ることが目的
- **プロの鑑定**: 正確な万年暦と専門知識に基づく詳細な鑑定

#### 推奨される使用方法

- 教育・学習目的での使用
- おおよその命式の把握
- 四柱推命への興味・関心の入り口として

**重要な判断や鑑定には、専門家による正確な鑑定を受けることをお勧めします。**

### 実装済みの機能（v2.0）

以下の機能が実装されています：

1. **✅ 正確な節気の実装**
   - 万年暦に基づく正確な節気の日時（1901-2040年）
   - 年ごとの節気データベース

2. **✅ 万年暦データの組み込み**
   - 正確な日柱の参照データ（1901-2040年）
   - 節気日時データと日干支データ

3. **✅ 蔵干の計算**
   - 地支に隠れている天干の算出
   - 余気・中気・本気の3層構造

4. **✅ 通変星の算出**
   - 日柱の天干を基準とした通変星の判定
   - 各柱の天干・蔵干の通変星

### 今後の改善予定

以下の機能拡張を検討しています：

1. **対応年範囲の拡大**
   - 1901年以前、2040年以降への対応
   - より広範囲な万年暦データの組み込み

2. **正式な対応表の実装**
   - 月柱・時柱の正確な対応表
   - 伝統的な口訣の実装

3. **大運の計算**
   - 10年ごとの運勢の変化
   - 順行・逆行の判定

4. **十二運の算出**
