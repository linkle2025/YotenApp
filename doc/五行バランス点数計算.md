# 五行バランス点数計算システム

## 概要

命式の天干と蔵干から五行（木・火・土・金・水）のバランス点数を計算し、月令と天干の有無を考慮した補正を適用するシステムです。

## 計算ルール

### 1. 基本点数

#### 天干の点数
- 各天干: **10点**

#### 蔵干の点数

| 地支 | 本気 | 中気 | 余気 |
|------|------|------|------|
| 子 | 20点 | - | - |
| 卯 | 20点 | - | - |
| 酉 | 20点 | - | - |
| 午 | 20点（丁のみ） | 0点（己） | - |
| その他 | 10点 | 5点 | 5点 |

**特殊ルール**:
- 亥が存在する場合、その個数分だけ土の余気に +5点を加算

### 2. 月令による倍化

月支（月柱の地支）の五行を得る要素の点数を **2倍** にします。

例：月支が寅（木）の場合、木の五行の合計点数を2倍

### 3. 死令による半減

月支の五行から相剋される五行の点数を **1/2** にします。

相剋の順序：木→土→水→火→金→木

例：月支が寅（木）の場合、木が剋する土の点数を1/2

### 4. 天干に無い五行の半減

4つの天干（年・月・日・時）に存在しない五行の点数を **1/2** にします。

## デバッグ出力例

```
=== 五行バランス点数計算 ===

【1. 天干の点数（各10点）】
  年柱天干: 乙（wood） +10点
  月柱天干: 辛（metal） +10点
  日柱天干: 丙（fire） +10点
  時柱天干: 癸（water） +10点
  天干に存在する五行: wood, metal, fire, water

【2. 蔵干の点数】
  年柱地支: 丑
    本気: 己（earth） +10点
    中気: 辛（metal） +5点
    余気: 癸（water） +5点
  月柱地支: 巳
    本気: 丙（fire） +10点
    中気: 庚（metal） +5点
    余気: 戊（earth） +5点
  ...

【3. 月令による倍化】
  月支: 巳（fire）
  fireを得る → 20点 × 2 = 40点

【4. 死令による半減】
  月支のfireが剋する五行: metal
  metalは死令 → 30点 ÷ 2 = 15点

【5. 天干に無い五行の半減】
  earthは天干に無し → 15点 ÷ 2 = 7.5点

【最終結果】
  wood: 10.0点
  fire: 40.0点
  earth: 7.5点
  metal: 15.0点
  water: 15.0点
```

## 注意事項

### 時間不明の場合

- 時柱は計算対象外
- 天干は年・月・日の3つのみで判定
- デバッグ情報に「（時間不明のためスキップ）」と表示

### 亥の特殊ルール

亥の蔵干は本来、本気：壬、中気：甲で余気はNoneですが、このルールにより、亥を持つ場合はその個数分、土の余気に +5点を加点します。

例：亥が2個ある場合 → 土に +10点
