# 干合（かんごう）判定機能

## 概要

命式において、天干同士が特定の組み合わせになる場合、「干合」が成立します。干合が成立した天干は金色のボーダーで強調表示され、詳細情報が表示されます。

## 干合とは

干合（かんごう）は、天干同士が特定の組み合わせで結びつく現象です。干合が成立すると、その天干の性質が変化します。

## 干合の組み合わせ

以下の5つの組み合わせで干合が成立します：

| 組み合わせ | 化する五行 |
|-----------|-----------|
| 甲 + 己 | 土 |
| 乙 + 庚 | 金 |
| 丙 + 辛 | 水 |
| 丁 + 壬 | 木 |
| 戊 + 癸 | 火 |

## 成立条件

### 隣接する柱の間でのみ成立

干合は、**隣接する柱の間**でのみ成立します：

- ✅ **時柱と日柱**の間
- ✅ **日柱と月柱**の間
- ✅ **月柱と年柱**の間
- ❌ **時柱と年柱**の間（隣接していないため成立しない）

### 例

```
時柱: 癸巳
日柱: 戊申  ← 戊と癸で干合成立（時柱と日柱）
月柱: 甲寅
年柱: 己丑  ← 甲と己で干合成立（月柱と年柱）
```

この例では2つの干合が成立：
1. 時柱の癸と日柱の戊
2. 月柱の甲と年柱の己

## 表示仕様

### 1. ボーダー表示

干合が成立している天干のセルに、金色のボーダーを適用：

```css
border: 9px solid gold;
box-shadow: 0 0 10px rgba(255, 215, 0, 0.5);
```

### 2. 成立情報の表示

命式テーブルの右下に、small文字で干合の成立情報を表示：

```
癸干と戊干が干合成立（時柱と日柱）
甲干と己干が干合成立（月柱と年柱）
```

## 実装詳細

### 判定ロジック

```javascript
// 干合の組み合わせをチェック
const checkKangou = (stem1, stem2) => {
  const kangouPairs = {
    '甲': '己', '己': '甲',
    '乙': '庚', '庚': '乙',
    '丙': '辛', '辛': '丙',
    '丁': '壬', '壬': '丁',
    '戊': '癸', '癸': '戊'
  };
  return kangouPairs[stem1] === stem2;
};

// 干合が成立している柱を取得
const getKangouPillars = () => {
  const kangouList = [];
  
  // 時柱と日柱（時間不明でない場合のみ）
  if (!hour_unknown && checkKangou(hour_stem, day_stem)) {
    kangouList.push({ pillars: ['hour', 'day'], ... });
  }
  
  // 日柱と月柱
  if (checkKangou(day_stem, month_stem)) {
    kangouList.push({ pillars: ['day', 'month'], ... });
  }
  
  // 月柱と年柱
  if (checkKangou(month_stem, year_stem)) {
    kangouList.push({ pillars: ['month', 'year'], ... });
  }
  
  return kangouList;
};
```

## テスト方法

### テストケース1: 時柱と日柱の干合

**命式例**:
- 時柱: 癸巳
- 日柱: 戊申
- 月柱: 甲寅
- 年柱: 乙丑

**期待される結果**:
- 時柱の天干セルに金色のボーダー
- 日柱の天干セルに金色のボーダー
- 「癸干と戊干が干合成立（時柱と日柱）」と表示

### テストケース2: 日柱と月柱の干合

**命式例**:
- 時柱: 甲子
- 日柱: 己丑
- 月柱: 甲寅
- 年柱: 乙卯

**期待される結果**:
- 日柱の天干セルに金色のボーダー
- 月柱の天干セルに金色のボーダー
- 「己干と甲干が干合成立（日柱と月柱）」と表示

### テストケース3: 月柱と年柱の干合

**命式例**:
- 時柱: 甲子
- 日柱: 乙丑
- 月柱: 丙寅
- 年柱: 辛卯

**期待される結果**:
- 月柱の天干セルに金色のボーダー
- 年柱の天干セルに金色のボーダー
- 「丙干と辛干が干合成立（月柱と年柱）」と表示

### テストケース4: 複数の干合

**命式例**:
- 時柱: 甲子
- 日柱: 己丑
- 月柱: 乙寅
- 年柱: 庚卯

**期待される結果**:
- 時柱、日柱、月柱、年柱すべての天干セルに金色のボーダー
- 「甲干と己干が干合成立（時柱と日柱）」と表示
- 「乙干と庚干が干合成立（月柱と年柱）」と表示

### テストケース5: 干合なし

**命式例**:
- 時柱: 甲子
- 日柱: 乙丑
- 月柱: 丙寅
- 年柱: 丁卯

**期待される結果**:
- 金色のボーダーなし
- 干合の表示なし

### テストケース6: 時間不明の場合

**命式例**:
- 時柱: （時間不明）
- 日柱: 戊申
- 月柱: 癸酉
- 年柱: 甲戌

**期待される結果**:
- 日柱と月柱の天干セルに金色のボーダー
- 「戊干と癸干が干合成立（日柱と月柱）」と表示
- 時柱は判定対象外

## 干合の意味（参考）

### 甲己合化土
- 甲（木）と己（土）が合わさると、土に化する
- 中正の合とも呼ばれる

### 乙庚合化金
- 乙（木）と庚（金）が合わさると、金に化する
- 仁義の合とも呼ばれる

### 丙辛合化水
- 丙（火）と辛（金）が合わさると、水に化する
- 威制の合とも呼ばれる

### 丁壬合化木
- 丁（火）と壬（水）が合わさると、木に化する
- 淫慝の合とも呼ばれる

### 戊癸合化火
- 戊（土）と癸（水）が合わさると、火に化する
- 無情の合とも呼ばれる

## よくある質問

### Q1: 時柱と年柱で干合の組み合わせがある場合は？
A: 時柱と年柱は隣接していないため、干合は成立しません。

### Q2: 時間不明の場合は？
A: 時柱が存在しないため、時柱と日柱の干合は判定されません。日柱と月柱、月柱と年柱の干合は通常通り判定されます。

### Q3: 干合が成立すると命式にどう影響する？
A: 干合が成立すると、その天干の性質が変化し、化した五行の性質を帯びます。これは命式の解釈において重要な要素となります。

### Q4: 複数の干合が同時に成立することはある？
A: はい、例えば時柱と日柱、月柱と年柱で同時に干合が成立することがあります。
