# 脆弱性スキャン手順・成果物

一般公開前および定期運用で、依存パッケージの既知脆弱性を確認する手順です。

## 1. バックエンド（Python / Django）

### 手順

```bash
cd backend

# 仮想環境を有効化してから実行
pip install pip-audit
pip-audit
```

`pip-audit` が利用できない場合は、以下で代替確認できます。

```bash
pip list --outdated
# 併せて https://pyup.io/safety/ や Django のセキュリティリリースを確認
```

## 2. フロントエンド（Node / npm）

### 手順

```bash
cd frontend
npm audit
```

修正を自動適用する場合（破壊的変更に注意）:

```bash
npm audit fix
# 破壊的変更を含む場合は
# npm audit fix --force は依存関係を壊す可能性があるため、内容を確認してから実行
```

## 3. 運用上の注意

- **一般公開前**: 重大（Critical）・高（High）は必ず解消してから公開する。
- **定期実行**: 四半期ごと、または重要な依存関係のアップデート後に実行することを推奨。
- **CI での自動実行**: 任意で、`pip-audit` および `npm audit` を CI パイプラインに組み込み、脆弱性検出時に失敗させる設定が可能。
