# 鑑定スキル表（現代ビジネス版）α版

## 概要

命式（通変星・五行バランス・身旺身弱・格局）から、**9つの能力値**と**7つの職種ランク**を算出し、鑑定表ページ（DetailPage）に表示する機能です。全ユーザーに表示します。

- 計算結果は **DBに保存しません**。API レスポンスを返すときに `SerializerMethodField` で算出します（マイグレーション不要）。
- 既存の計算ロジック（`calculators.py`、五行バランス、格局、フロントの身旺判定）は**変更していません**。参照だけしています。
- 用語・基礎点・重み・ランク帯は `backend/apps/fortune/skill_sheet.py` の定数で一元管理しています。この定数を書き換えるだけで調整できます。

## 入力データ

### 五行グループ点数 E

`five_elements_balance_data.scores`（wood/fire/earth/metal/water）を、日干の五行を基準に5つのグループへ振り分けます。

| グループ | 日干の五行との関係 |
|---|---|
| 比劫 | 日干と同じ五行 |
| 印 | 日干を生じる五行 |
| 食傷 | 日干が生じる五行 |
| 財 | 日干が剋す五行 |
| 官 | 日干を剋す五行 |

### 通変星点数 P

通変星ごとに、下の重みで点数を合計します。**日干そのもの（日柱の天干）は含めません。**

| 対象 | 重み |
|---|---|
| 天干（年・月・時） | 10 |
| 蔵干・本気 | 10（子・卯・酉の本気、午の丁は20） |
| 蔵干・中気 | 5（午の己は0） |
| 蔵干・余気 | 5 |

- 重みは [五行バランス点数計算.md](./五行バランス点数計算.md) の手順1〜2と同じです。月令による倍化、死令による半減、天干に無い五行の半減は**適用しません**。亥の特殊ルール（土の余気に+5）は、該当する通変星がないため対象外です。
- `hour_unknown=True` の場合は、時柱（天干・蔵干）を除外します。
- モデルのフィールドのうち、`*_hidden_stem_secondary` が余気、`*_hidden_stem_tertiary` が中気です。

### 身旺度 D

```
D = (E比劫 + E印) − (E食傷 + E財 + E官)
D > 0 → 身旺 ／ D < 0 → 身弱 ／ D = 0 → 中和
```

判定の仕組みは、フロントの `getStrengthLabel`（[身旺身弱判定.md](./身旺身弱判定.md)）と同じです。フロントでは中和を「-」と表示します。

### 格補正 K

`kakukyoku` に該当する格名が**含まれていれば** +10 します。「◯格または◯格」の場合は両方とも該当とみなします。ただし、同じ能力への加算は最大 +10 です。

## 能力値の算出式

```
企画 = 30 + E食傷 + 0.5×(P食神+P傷官) + K(食神格|傷官格)
知略 = 37 + E印   + 0.5×(P偏印+P印綬) + K(偏印格|印綬格)
実行 = 45 + 0.5×E食傷 + 0.5×E比劫 + S(身旺:+10 / 身弱:−10 / 中和:0)
体力 = 52 + 0.6×(E比劫+E印)
人望 = 40 + 0.5×(P比肩+P食神+P偏財)
統率 = 30 + E官 + 0.5×(P正官+P偏官) + S(身旺:+5 / 身弱:−5 / 中和:0) + K(正官格|偏官格)
開拓 = 35 + P偏官 + P劫財
商才 = 30 + E財 + 0.5×(P正財+P偏財) + K(正財格|偏財格)
管理 = 25 + P正官 + P正財
```

- 先頭の定数は**基礎点**（`BASE_POINTS`）です。石川さんの命式1件に合わせて校正した値です。
- 丸めは**四捨五入（0.5は切り上げ）**で、その後 0〜100 の範囲に収めます。浮動小数点の誤差（例：57.5 が 57.4999… になる）を避けるため、計算には `Decimal` の `ROUND_HALF_UP` を使います。

## 職種ランク

能力値（丸め後の整数）で加重平均をとり、四捨五入してからランクを判定します。

```
将軍   = 0.3×統率 + 0.3×体力 + 0.2×開拓 + 0.2×商才
軍師   = 0.4×知略 + 0.4×企画 + 0.2×人望
教官   = 0.5×企画 + 0.5×知略
専門職 = 0.5×実行 + 0.5×知略
営業   = 0.4×開拓 + 0.4×人望 + 0.2×体力
現場L  = 0.4×統率 + 0.3×体力 + 0.3×人望
総務   = 0.6×管理 + 0.4×商才
```

| 点数 | ランク |
|---|---|
| 85以上 | S |
| 80〜84 | A+ |
| 75〜79 | A |
| 70〜74 | B+ |
| 65〜69 | B |
| 60〜64 | B- |
| 55〜59 | C+ |
| 50〜54 | C |
| 45〜49 | C- |
| 44以下 | D |

## API レスポンス（`skill_sheet`）

`GET /api/fortune/history/{id}/` などのレスポンスに `skill_sheet` が含まれます。

```json
{
  "version": "alpha-1",
  "is_reference": false,
  "strength": {"label": "身旺", "diff": 17.5},
  "kakukyoku": "傷官格",
  "abilities": [{"key": "kikaku", "name": "企画", "meaning": "ゼロから構想を描く", "score": 90}],
  "jobs": [{"key": "kyoukan", "name": "教官", "meaning": "学びを設計し、人を育てる", "score": 86, "rank": "S"}],
  "inputs": {
    "element_groups": {"比劫": 25.0, "印": 30.0, "食傷": 25.0, "財": 2.5, "官": 10.0},
    "star_points": {"比肩": 10, "劫財": 5, "食神": 35, "...": 0}
  },
  "day_stem": "己",
  "day_stem_type": "田畑"
}
```

- `abilities` と `jobs` は、上の用語表と同じ表示順で返します。職種をランク順に並べ替えることはしません。
- `is_reference` には `hour_unknown` と同じ値が入ります。
- `inputs` はデバッグ表示用です。
- `day_stem_type` は十干マスタ（`apps.stems.Stem.element_type`）の値です。マスタが空の場合は空文字になります。
- `five_elements_balance_data` が空の古いレコードでは `null` を返し、画面にも表示しません。

## 今後の課題

- 基礎点はサンプル1名で校正した値で、他の人の点数分布はまだ検証していません。α版の公開後に塾生数名の結果を見て、`BASE_POINTS` と `JOB_WEIGHTS` を見直す前提です。
- 点数の高い人は上限100に張り付く可能性があります（例：印が非常に強い命式の知略）。
- 対象外としたもの（将来対応）：十二大従星・十大主星、傷官見官や印過多などの特殊ルール、異常干支、天中殺、大運・年運との連動、称号の自動生成、レーダーチャート。
