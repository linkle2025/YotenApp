# 五行バランスの表示順序

## 概要

鑑定表ページの「五行バランス」セクションにおいて、命式の日干を基準に五行を時計回りに配置します。

## 表示ルール

### 基本ルール

1. **日干の五行を上（中央上）に配置**
2. **そこから時計回りに、木→火→土→金→水の順番で配置**

### 配置位置

```
     [上]
[左]     [右]
  [下左][下右]
```

### 五行の相生順

木 → 火 → 土 → 金 → 水 → 木 → ...（繰り返し）

## 具体例

### 例1: 日干が壬（水）の場合

日干の五行: 水

配置:

  金      木
   土   火

- 上: 水（日干）
- 右: 木（水の次）
- 下右: 火（木の次）
- 下左: 土（火の次）
- 左: 金（土の次）

## 実装詳細

### 天干から五行へのマッピング

| 天干 | 五行 |
|------|------|
| 甲・乙 | 木 |
| 丙・丁 | 火 |
| 戊・己 | 土 |
| 庚・辛 | 金 |
| 壬・癸 | 水 |

### 処理フロー

1. 日干の天干を取得（例: 壬）
2. 天干から五行を判定（例: 壬 → 水）
3. 五行の相生順配列での位置を取得（例: 水 → index 4）
4. その位置から時計回りに5つの五行を配置
   - 上: 水（index 4）
   - 右: 木（index 0）
   - 下右: 火（index 1）
   - 下左: 土（index 2）
   - 左: 金（index 3）

### コード実装

```javascript
// 五行の相生順
const elementOrder = ['wood', 'fire', 'earth', 'metal', 'water'];

// 日干の五行から開始インデックスを取得
const startIndex = elementOrder.indexOf(dayStemElement);

// 時計回りに配置
const orderedElements = [];
for (let i = 0; i < 5; i++) {
  const index = (startIndex + i) % 5;
  orderedElements.push(elementOrder[index]);
}

// 配置
// orderedElements[0]: 上
// orderedElements[1]: 右
// orderedElements[2]: 下右
// orderedElements[3]: 下左
// orderedElements[4]: 左
```

## よくある質問

### Q1: なぜ時計回りなのか？
A: 五行の相生（木生火、火生土、土生金、金生水、水生木）の順序を視覚的に表現するためです。

### Q2: 五行の順番は固定？
A: はい、木→火→土→金→水の順番は固定で、これが五行の相生の順序です。

### Q3: 日干が不明な場合は？
A: 日干が取得できない場合は、デフォルトで木から開始します。
