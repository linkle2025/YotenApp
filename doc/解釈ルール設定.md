# 解釈ルール設定（skill_rules.toml）

鑑定スキル表の点数補正と、判定の要点（AI解説）の読み方を、コードを書かずに調整するための設定ファイルです。

- ファイル: `backend/apps/fortune/rules/skill_rules.toml`
- 読み込み・判定: `backend/apps/fortune/skill_rules.py`
- テスト: `backend/apps/fortune/tests/test_skill_rules.py`

## 何に効くか

| 設定 | 鑑定スキル表の点数 | AI解説 |
|---|---|---|
| `principles`（読み方の原則） | － | システム指示の「読み方の原則」にそのまま入る |
| `strength_roles`（身旺・身弱ごとの五行の喜忌） | － | `element_relations` の `role` として渡す |
| `day_stems`（日干ごとの性質） | `adjust` を書けば補正 | `day_stem` の `nature`・`strengths`・`cautions` として渡す（解説の起点） |
| `[[rules]]`（判定ルール） | `adjust` で補正 | 条件に合ったルールの `interpretation` を `applied_rules` として渡す |

基本の考え方は**日干を起点にする**ことです。五行の点数をそのまま能力にするのではなく、日干の強さ（身旺・身弱）と、日干から見た関係（日干を生じる・剋す など）で効き方を変えます。

例：癸（みずのと）・身弱で、官（土）が100と最も強い命式。旧版は官の量がそのまま統率100になっていました。今は「身弱で官が重い（身弱殺重）」のルールで、官は統率ではなく規律・管理の側に効きます（統率45、管理60）。

## 反映のタイミング

- ファイルを保存すると、次の計算から反映されます。**サーバーの再起動は不要**です（更新時刻を見て読み直します）。
- 本番では、Git でプッシュしてデプロイすると反映されます。
- 内容が変わると、AI解説の入力（`rules_version` と点数）が変わります。
  - 鑑定表ページでは、古い解説は表示されなくなり、「判定の要点を生成」ボタンが出ます。新しい点数で作り直せます。
  - 生成は1日の上限（`SKILL_INSIGHT_DAILY_LIMIT`）に数えます。
- 書き換えたら、先頭の `version` の日付も更新してください（管理用です）。

## 新版（移行中）への反映

サーバーレス版への移行中は、新版の計算ロジック（`packages/meishiki`）にも同じ設定ファイルの写し（`packages/meishiki/rules/skill_rules.toml`）があります。現行版の設定を書き換えたら、次の手順で新版にも反映してください。2つの内容が違うと、新版のテストが失敗して知らせます。

```bash
cp backend/apps/fortune/rules/skill_rules.toml packages/meishiki/rules/skill_rules.toml
pnpm --filter @yoten/meishiki generate:rules
pnpm test
```

内容を変えると、新版の比較テストが「比較用データと解釈ルールの版が違う」と知らせます。そのときは、`packages/meishiki/README.md` の手順で比較用データを作り直してください（わからなければ開発担当に依頼）。

## 書式の注意

- 形式は [TOML](https://toml.io/ja/) です。`#` から行末まではコメントです。
- **日本語の項目名は `"財"` のように引用符で囲みます。** 例：`group_below = { "官" = 10 }`、`[day_stems."庚"]`
- 書き間違いがあると、鑑定スキル表は表示されなくなり（誤った点数を出さないため）、バックエンドのログに場所と内容が出ます。
  - 例：`解釈ルール設定の誤り（rules 3件目（id=zai_in_conflict） の adjust 1件目）: ability が不正です`
- 書き換えたら、テストで確認できます。

```bash
docker compose exec backend python manage.py test apps.fortune.tests.test_skill_rules
```

## principles（読み方の原則）

AI への指示に、番号付きでそのまま入ります。上から順に重要です。

```toml
principles = [
  "日干を最重要の起点にする。……",
  "五行の点数は量に加味して、日干から見た関係でも読む。……",
]
```

## strength_roles（身旺・身弱ごとの喜忌）

身旺・身弱・中和のそれぞれについて、5グループの役割を `喜`（助けになる）・`忌`（過剰・負担）・`中`（どちらにも働く）で書きます。命式画面の説明（身旺は食傷・財を強める、身弱は比劫・印を強める、官は中立）に合わせています。

```toml
[strength_roles."身弱"]
"比劫" = "喜"
"印" = "喜"
"食傷" = "忌"
"財" = "忌"
"官" = "中"
```

## day_stems（日干ごとの性質）

十干それぞれの性質を書きます。AI解説は、ここを起点に組み立てます。

```toml
[day_stems."癸"]
nature = "雨・露。静かに染み込み、周囲を潤す。"
strengths = "静かな知性、浸透力、裏方で支える力、忍耐"
cautions = "自己主張が控えめで、押しの強さや持久力は出にくい"
# adjust = [{ ability = "jinbou", value = 5 }]   ← 日干そのものに点数補正をかけたい場合
```

日干の比喩（田畑、鉄・鉱石など）は、十干マスタ（`element_type`）の値も `day_stem.type` として渡しています。

## [[rules]]（判定ルール）

1つのルールは `[[rules]]` から始まるブロックです。

```toml
[[rules]]
id = "mijaku_kan_heavy"                 # 半角英数字の識別子（重複不可）
title = "身弱で官が重い（身弱殺重）"      # 画面の内訳・AI解説に出る名前
when = { strength = ["身弱"], top_group = "官" }
interpretation = "官（日干を剋す、規律・組織の力）が {官} と最も強いが、……"
adjust = [
  { ability = "touritsu", per = "官", value = -1.0 },
  { ability = "kanri", per = "官", value = 0.3, max = 25 },
]
```

### when（条件）

書いた条件をすべて満たすと適用されます。`when` を省略すると全員に適用されます。

| 条件 | 書き方の例 | 意味 |
|---|---|---|
| `strength` | `["身弱"]` | 身旺・身弱・中和のいずれか |
| `day_stem` | `["庚", "辛"]` | 日干 |
| `day_element` | `["金"]` | 日干の五行（木・火・土・金・水） |
| `top_group` | `"官"` | そのグループが5つの中で最大（同点も含む） |
| `group_at_least` | `{ "財" = 30, "印" = 30 }` | グループの点数がその値以上（すべて） |
| `group_below` | `{ "官" = 10 }` | グループの点数がその値未満（すべて） |
| `group_rank_within` | `{ "食傷" = 2 }` | グループの順位がその値以内 |
| `strength_diff_at_least` / `strength_diff_below` | `50` | 身旺度（比劫＋印 −（食傷＋財＋官））がその値以上／未満 |
| `kakukyoku_any` | `["偏官格"]` | 格局にいずれかの格名を含む |
| `stem_stars` | `[["傷官"], ["正官", "偏官"]]` | 天干（日干を除く）に、各リストの星が1つ以上ずつある |

グループは日干から見た5つ（比劫・印・食傷・財・官）で、点数は五行バランスの点数です。時間不明の場合、時干は `stem_stars` の判定に使いません。

### interpretation（解釈）

AI解説に「確定した解釈」として渡す文です。AI は、補正のかかった能力や関係する職種の説明で、この解釈を根拠に使います。

`{財}` `{官}` などで点数を差し込めます。使える名前：五行グループ（比劫・印・食傷・財・官）、通変星（比肩〜印綬の点数）、`{身旺度}`、`{日干}`。

### adjust（点数補正）

能力の点数に足し引きします。補正は能力の内訳（`breakdown`）にルールの `title` で記録されます。

| 項目 | 内容 |
|---|---|
| `ability` | 能力：`kikaku` 企画 / `chiryaku` 知略 / `jikkou` 実行 / `tairyoku` 体力 / `jinbou` 人望 / `touritsu` 統率 / `kaitaku` 開拓 / `shousai` 商才 / `kanri` 管理 |
| `value` | 足す点数（マイナスで減点） |
| `per` | 掛ける元の値（省略すると `value` をそのまま足す）。五行グループ名、通変星名、`"身旺度"`、またはそれらのリスト（合計に掛ける） |
| `min` / `max` | 補正量の下限・上限 |

例：
- `{ ability = "kanri", value = -10 }` → 管理を10点下げる
- `{ ability = "touritsu", per = "官", value = -1.0 }` → 統率から官の点数をそのまま引く（官を統率に数えない）
- `{ ability = "tairyoku", per = "身旺度", value = 0.3, min = -30 }` → 身旺度 −90 なら体力 −27（最大 −30 まで）

補正後の点数は、これまでどおり四捨五入して0〜100に収めます。職種ランクは補正後の能力から計算します。

## 点数の式そのものを変えたいとき

基礎点・五行や星の重み・職種の重み・ランク帯は、これまでどおり `skill_sheet.py` の定数です（[鑑定スキル表.md](./鑑定スキル表.md)）。身旺身弱の固定補正（実行±10・統率±5）と格補正（+10）も `skill_sheet.py` にあります。
