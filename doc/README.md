## 📝 ドキュメント更新ルール

ドキュメントは常に最新の状態を保つことが重要です。以下のルールに従ってください：

### 更新が必要なタイミング

- ✅ 新しいAPIエンドポイントを追加したとき
- ✅ ページやコンポーネントを追加・変更したとき
- ✅ データベーススキーマを変更したとき
- ✅ 環境変数を追加・変更したとき
- ✅ 重要な設定変更を行ったとき
- ✅ 新しい機能を実装したとき

### 更新方法

1. 該当するドキュメントファイルを編集
2. 変更内容を簡潔に記載
3. 必要に応じてコード例やスクリーンショットを追加
4. Gitコミット時に `[docs]` プレフィックスを付ける

```bash
git commit -m "[docs] APIエンドポイント追加に伴うドキュメント更新"
```
