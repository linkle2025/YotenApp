# 奇門遁甲・時盤（作盤）の各宮点数計算

管理者向け「奇門遁甲」画面で、洛書九宫の**各宮に表示される点数**の算出ルールをまとめたものです。  
命式の「五行バランス点数」（[五行バランス点数計算.md](./五行バランス点数計算.md)）とは**別系統**であり、本ドキュメントの対象外です。

## 実装箇所

| 項目 | 場所 |
|------|------|
| 点数の合算 | `backend/apps/fortune/calculators.py` の `calculate_palace_score` |
| 呼び出し | 同ファイル `calculate_kimon_tonkou_board` 内で、位置 1〜9 の各宮に対し `palace['score']` を設定（**中宮・位置5は `None`**） |
| 表示 | `frontend/src/pages/KimonTonkouPage.js`（盤上オーバーレイ） |

## 基本方針

- 一宮あたりの点数は **非負の整数**で、**八門・八神・九星・天盤干・地盤干**のうち、下表に該当する要素の点数を**単純合算**したものです。
- 該当しない要素（表に無い八門・九星など）は **0 点**（その項目は加算しない）。
- **中宮（位置5）**には点数を付けません（`score` は `null` / 非表示）。

## 八門（各宮の `hachimon`）の点数

| 八門 | 点数 |
|------|------|
| 休 | 40 |
| 生 | 40 |
| 開 | 40 |
| 景 | 20 |
| 上記以外（傷・杜・死・驚） | 0 |

## 八神（各宮の `hasshin`）の点数

| 八神 | 点数 |
|------|------|
| 符 | 20 |
| 陰 | 20 |
| 合 | 20 |
| 地 | 20 |
| 天 | 20 |
| 上記以外（蛇・陳・雀） | 0 |

## 九星（各宮の `kyusei`）の点数

| 九星 | 点数 |
|------|------|
| 任 | 10 |
| 冲 | 10 |
| 輔 | 10 |
| 心 | 10 |
| 上記以外（蓬・英・芮・柱） | 0 |

## 天盤干（各宮の `tenban_kan`）の点数

| 天干 | 点数 |
|------|------|
| 乙 | 10 |
| 丙 | 10 |
| 丁 | 10 |
| 上記以外 | 0 |

**リスト形式**: 天盤干が `[干1, 干2]` のように配列で返る宮がある（地盤干の複製など）。その場合は**各要素を個別に**上表で判定し、該当分を**加算の和**とする。

## 地盤干（各宮の `jiban_kan`）の点数

| 天干 | 点数 |
|------|------|
| 乙 | 10 |
| 丙 | 10 |
| 丁 | 10 |
| 上記以外 | 0 |

**括弧表記**: 旬首地盤干などで表示用に括弧が付く場合、計算前に **`()` を除去**した文字列で上表と照合する（例: `(戊)` → `戊` は表に無いので 0 点）。

## 計算例（イメージ）

ある宮で  
八門=休（40）・八神=符（20）・九星=輔（10）・天盤干=乙（10）・地盤干=丙（10）  
のとき → **40 + 20 + 10 + 10 + 10 = 90 点**

## 変更時の注意

- 点数テーブルを変えた場合は、**本ドキュメントと `calculate_palace_score` を同期**してください。
- 作盤アルゴリズム（九星・八門の配置）自体の説明は本書の範囲外です。コード上の配置は `calculate_kimon_tonkou_board` および `place_*` 系関数を参照してください。
