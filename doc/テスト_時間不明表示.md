# 時間不明表示のテスト手順

## 目的
時間不明の場合に、時柱の列が表示され、天干・地支・蔵干に「ー」が表示されることを確認する。

## テスト環境
- ブラウザ: Chrome/Safari/Firefox
- URL: http://localhost:3000

## テスト手順

### 1. 時間が分かる場合（通常）

1. `/calculate` ページにアクセス
2. 以下の情報を入力：
   - 生年月日: 1985年5月10日
   - 「□時間不明」: **チェックなし**
   - 生時分: 11時30分
   - 都道府県: 岐阜県
   - 性別: 男性
3. 「命式を作成」をクリック

**期待される結果**:
- 詳細ページに遷移
- 生年月日の表示: 「1985年5月10日 11時30分」
- 時柱の列が表示される
- 時柱に干支が表示される（例: 癸巳）
- 時柱の天干・地支・蔵干が正常に表示される

### 2. 時間が不明な場合

1. `/calculate` ページにアクセス
2. 以下の情報を入力：
   - 生年月日: 1985年5月10日
   - 「□時間不明」: **チェックあり**
   - 生時分: （無効化されている）
   - 都道府県: 岐阜県
   - 性別: 男性
3. 「命式を作成」をクリック

**期待される結果**:
- 詳細ページに遷移
- 生年月日の表示: 「1985年5月10日（時間不明）」
- 時柱の列が表示される ✓
- 時柱の天干に「ー」が表示される ✓
- 時柱の地支に「ー」が表示される ✓
- 時柱の蔵干に「ー」が表示される ✓
- 「ー」は灰色（#999）で表示される ✓
- 五行の背景色は適用されない ✓
- 年柱、月柱、日柱は通常通り表示される

## チェックポイント

### 視覚的な確認

| 項目 | 時間あり | 時間不明 |
|------|----------|----------|
| 時柱ヘッダー | ✓表示 | ✓表示 |
| 時柱天干 | 干支表示 | ー |
| 時柱地支 | 干支表示 | ー |
| 時柱蔵干 | 干支表示 | ー |
| 五行背景色 | ✓適用 | ✗適用なし |
| 生年月日表示 | XX時XX分 | （時間不明）|

### ブラウザコンソール確認

1. 開発者ツールを開く（F12）
2. コンソールタブを確認
3. エラーが表示されていないことを確認

### レスポンシブ確認

1. ブラウザのウィンドウサイズを変更
2. スマートフォン表示にする
3. 時柱が正しく表示されることを確認
4. 「ー」が正しく表示されることを確認
