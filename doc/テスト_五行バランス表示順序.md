# 五行バランス表示順序のテスト

## テスト目的

日干を基準に五行が時計回りに正しく配置されることを確認する。

## テスト環境

- URL: http://localhost:3000
- ブラウザ: Chrome/Safari/Firefox

## テストデータ

**テストケース**: 1985年5月10日生まれ
- 日干: 甲（木）

**期待される配置**:
```
     木（上）
水（左）  火（右）
  金（下左）土（下右）
```

## テスト手順

### 1. 準備

```bash
# バックエンドが起動していることを確認
docker-compose ps

# フロントエンドのキャッシュをクリア
Cmd+Shift+R (Mac) / Ctrl+Shift+R (Windows)
```

### 2. 各パターンの確認

各テストケースについて以下を実行：

1. `/calculate` ページで命式を作成
2. 詳細ページに遷移
3. 「五行バランス」セクションを確認
4. 五行の配置が期待通りか確認

### 3. チェックポイント

- [ ] 上の位置に日干の五行が表示されている
- [ ] 右の位置に日干の次の五行が表示されている
- [ ] 下右の位置に2つ先の五行が表示されている
- [ ] 下左の位置に3つ先の五行が表示されている
- [ ] 左の位置に4つ先の五行が表示されている
- [ ] 各五行の色が正しく表示されている
- [ ] レイアウトが崩れていない
