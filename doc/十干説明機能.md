# 十干説明機能 仕様書

## 概要

四柱推命における十干（じっかん：甲・乙・丙・丁・戊・己・庚・辛・壬・癸）の詳細説明を提供する機能です。

- バックエンドでデータを管理し、APIとして提供
- フロントエンドで一覧表示とモーダル詳細表示
- 鑑定表（/fortune/x）の日干からも直接アクセス可能
- 将来のスマートフォンアプリでも同じAPIを使用可能

### 2. データモデル

**モデル名**: `Stem`  
**テーブル名**: `stems_stem`

| フィールド名 | 型 | 制約 | 説明 |
|------------|-----|-----|------|
| id | AutoField | PK | 自動採番ID |
| name | CharField(1) | UNIQUE | 十干（甲、乙、丙...） |
| reading | CharField(10) | - | 読み仮名（きのえ、きのと...） |
| element_type | CharField(20) | - | タイプ名（樹木、草花、太陽...） |
| description | TextField | - | 詳細説明（複数段落） |
| personality | TextField | - | 人物像 |
| strengths | TextField | - | 強み・活かし方 |
| weaknesses | TextField | - | 弱み・接し方の注意点 |
| order | IntegerField | default=0 | 表示順序（1-10） |
| created_at | DateTimeField | auto_now_add | 作成日時 |
| updated_at | DateTimeField | auto_now | 更新日時 |

**モデル定義**: `backend/apps/stems/models.py`

```python
class Stem(models.Model):
    """十干（じっかん）モデル"""
    name = models.CharField(max_length=1, unique=True, verbose_name='十干')
    reading = models.CharField(max_length=10, verbose_name='読み仮名')
    element_type = models.CharField(max_length=20, verbose_name='タイプ')
    description = models.TextField(verbose_name='詳細説明')
    personality = models.TextField(verbose_name='人物像')
    strengths = models.TextField(verbose_name='強み・活かし方')
    weaknesses = models.TextField(verbose_name='弱み・接し方の注意点')
    order = models.IntegerField(default=0, verbose_name='表示順序')
    created_at = models.DateTimeField(auto_now_add=True, verbose_name='作成日時')
    updated_at = models.DateTimeField(auto_now=True, verbose_name='更新日時')

    class Meta:
        verbose_name = '十干'
        verbose_name_plural = '十干'
        ordering = ['order']

    def __str__(self):
        return f'{self.name}（{self.reading}）'
```

### 2. API通信サービス

**ファイル**: `frontend/src/services/stemService.js`

```javascript
import api from './api';

export const stemService = {
  /**
   * 十干一覧を取得
   * @returns {Promise<Array>} 十干データの配列
   */
  async getAllStems() {
    const response = await api.get('/stems/');
    // Django REST Frameworkのページネーションレスポンスからresultsを取り出す
    return response.data.results || response.data;
  },
};
```

### 5. 鑑定表からのアクセス

**ページ**: `/fortune/:id`（DetailPage）

**機能**:
- 日柱の天干（日干）をクリック可能に
- クリックでその場でモーダル表示（ページ遷移なし）
- 点線の下線とホバーエフェクトでクリック可能を明示

**実装**:
```javascript
// DetailPage.js
const [stems, setStems] = useState([]);
const [selectedStem, setSelectedStem] = useState(null);

// 十干データ取得
const loadStems = async () => {
  const data = await stemService.getAllStems();
  setStems(data);
};

// クリック処理
const handleStemClick = (stemName) => {
  const stem = stems.find(s => s.name === stemName);
  if (stem) {
    setSelectedStem(stem);
  }
};

// モーダル表示
{selectedStem && (
  <StemModal stem={selectedStem} onClose={handleCloseModal} />
)}
```

## トラブルシューティング

### エラー: stems.map is not a function

**原因**: APIレスポンスがページネーションオブジェクトのため、`results`を取り出す必要がある

**解決方法**: `stemService.js`で`response.data.results`を返すように修正

```javascript
return response.data.results || response.data;
```

---

### 十干データが表示されない

**確認項目**:
1. バックエンドが起動しているか: `docker-compose ps`
2. 初期データが投入されているか: `curl http://localhost:8000/api/stems/`
3. CORSエラーが出ていないか: ブラウザのコンソールを確認

**解決方法**:
```bash
# データ再投入
docker-compose exec backend python manage.py load_stems

# バックエンド再起動
docker-compose restart backend
```
