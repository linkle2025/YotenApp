## API エンドポイント

### 認証関連（`/api/auth/`）

| メソッド | エンドポイント | 説明 | 認証 |
|---------|--------------|------|-----|
| POST | `/api/auth/register/` | ユーザー登録 | 不要 |
| GET | `/api/auth/user/` | 現在のユーザー情報取得 | **必要** |
| POST | `/api/auth/password-reset/` | パスワードリセット用メールの送信（[パスワードリセット.md](./パスワードリセット.md)） | 不要 |
| POST | `/api/auth/password-reset/confirm/` | リセット用リンクの確認・パスワード再設定 | 不要 |

### トークン関連（`/api/token/`）

| メソッド | エンドポイント | 説明 | 認証 |
|---------|--------------|------|-----|
| POST | `/api/token/` | ログイン、アクセストークン取得 | 不要 |
| POST | `/api/token/refresh/` | リフレッシュトークンから新しいアクセストークンを取得 | 不要 |

### 四柱推命関連（`/api/fortune/`）

| メソッド | エンドポイント | 説明 | 認証 |
|---------|--------------|------|-----|
| POST | `/api/fortune/calculate/` | 四柱推命計算 | **必要** |
| GET | `/api/fortune/history/` | 計算履歴一覧 | **必要** |
| GET | `/api/fortune/history/{id}/` | 計算結果詳細 | **必要** |
| DELETE | `/api/fortune/history/{id}/delete/` | 履歴削除 | **必要** |
| PATCH | `/api/fortune/history/{id}/favorite/` | お気に入り切り替え | **必要** |
| GET | `/api/fortune/history/{id}/skill-insight/` | 判定の要点（保存済みの最新）を取得 | **必要** |
| POST | `/api/fortune/history/{id}/skill-insight/` | 判定の要点を生成（[判定の要点生成.md](./判定の要点生成.md)） | **必要** |

## モデル構成

### accounts アプリ

#### User（Djangoデフォルトモデル）

Django組み込みの `django.contrib.auth.models.User` を使用。

**フィールド**:
- `id`: 主キー
- `username`: ユーザー名（ユニーク）
- `email`: メールアドレス
- `password`: ハッシュ化されたパスワード
- `date_joined`: 登録日時

---

### fortune アプリ

#### FortuneCalculation（四柱推命計算結果）

**フィールド**:

| フィールド名 | 型 | 説明 |
|------------|---|------|
| `id` | AutoField | 主キー |
| `user` | ForeignKey | ユーザー（User モデル） |
| `name` | CharField | 氏名（任意、最大100文字） |
| `birth_year` | IntegerField | 生年 |
| `birth_month` | IntegerField | 生月（1-12） |
| `birth_day` | IntegerField | 生日（1-31） |
| `birth_hour` | IntegerField | 生時（0-23） |
| `prefecture` | CharField | 生まれた都道府県（デフォルト: 東京都） |
| `gender` | CharField | 性別（'male' or 'female'） |
| `year_pillar_heavenly_stem` | CharField | 年柱・天干 |
| `year_pillar_earthly_branch` | CharField | 年柱・地支 |
| `month_pillar_heavenly_stem` | CharField | 月柱・天干 |
| `month_pillar_earthly_branch` | CharField | 月柱・地支 |
| `day_pillar_heavenly_stem` | CharField | 日柱・天干 |
| `day_pillar_earthly_branch` | CharField | 日柱・地支 |
| `hour_pillar_heavenly_stem` | CharField | 時柱・天干 |
| `hour_pillar_earthly_branch` | CharField | 時柱・地支 |
| `is_favorite` | BooleanField | お気に入りフラグ |
| `created_at` | DateTimeField | 計算日時 |
| `updated_at` | DateTimeField | 更新日時 |

**インデックス**:
- `user` + `created_at`（履歴取得の高速化）

**権限**: IsAuthenticated

**機能**:
- JWTトークンから現在のユーザー情報を取得

### fortune アプリ

#### FortuneCalculationView（クラスベースビュー）

**URL**: `/api/fortune/calculate/`  
**メソッド**: POST  
**権限**: IsAuthenticated

**機能**:
- 生年月日時と性別から四柱推命を計算
- 計算結果をデータベースに保存

**計算内容**:

- 大運の算出（10年ごと、60歳まで）

## 認証・認可

### JWT認証

**使用ライブラリ**: `djangorestframework-simplejwt`

**トークンの種類**:
- **アクセストークン**: 有効期限1時間、API認証に使用
- **リフレッシュトークン**: 有効期限7日、アクセストークン更新に使用

**トークンローテーション**: 有効（セキュリティ向上）

**認証フロー**:
1. ログイン時に両方のトークンを取得
2. APIリクエスト時、アクセストークンを `Authorization: Bearer {token}` ヘッダーに付与
3. アクセストークン期限切れ時、リフレッシュトークンで新しいアクセストークンを取得

## 四柱推命計算ロジック（calculators.py）

### 主要な計算処理

1. **都道府県による時刻補正（経度差）**
   - 日本の標準時（東経135度）との経度差を考慮
   - 47都道府県それぞれの経度差を分単位で補正
   - 補正により日付が変わる場合は適切に処理
   - 例: 東京都は+19分、沖縄県は-29分

2. **均時差による時刻補正**
   - 月ごとの均時差（Equation of Time）を考慮
   - 地球の公転軌道が楕円であることによる太陽時と平均太陽時のずれを補正
   - 月別の補正値を適用（1月: -3分、2月: -13分、11月: +16分 など）

3. **時刻補正の統合**
   - 都道府県の経度差と均時差を合算して補正
   - 例: 東京都、1月生まれ → +19分 -3分 = +16分
   - 例: 沖縄県、2月生まれ → -29分 -13分 = -42分
   - 例: 北海道、11月生まれ → +25分 +16分 = +41分

4. **干支（天干・地支）の算出**
   - 年柱: 西暦から算出
   - 月柱: 年の天干と月から算出
   - 日柱: 基準日からの経過日数で算出
   - 時柱: 日の天干と時刻（補正後）から算出

### 都道府県の経度差マッピング

各都道府県の標準時との時差（分単位）:
- 東側の都道府県（北海道、東北など）: プラスの補正
- 西側の都道府県（九州、沖縄など）: マイナスの補正
- 兵庫県: 0分（標準時子午線が通過）

### 均時差マッピング

月ごとの均時差（分単位）:

| 月 | 均時差 | 説明 |
|----|--------|------|
| 1月 | -3分 | マイナス補正 |
| 2月 | -13分 | 年間で最大のマイナス補正 |
| 3月 | -12分 | マイナス補正 |
| 4月 | -4分 | マイナス補正 |
| 5月 | +3分 | プラス補正 |
| 6月 | +2分 | プラス補正 |
| 7月 | -3分 | マイナス補正 |
| 8月 | -6分 | マイナス補正 |
| 9月 | 0分 | 補正なし |
| 10月 | +10分 | プラス補正 |
| 11月 | +16分 | 年間で最大のプラス補正 |
| 12月 | +11分 | プラス補正 |
